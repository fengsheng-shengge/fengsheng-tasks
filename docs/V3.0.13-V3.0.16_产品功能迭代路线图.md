# 风声小程序 · 产品功能迭代路线图

> 日期：2026.8.4  
> 范围：V3.0.13 → V3.0.16  
> 核心方向：底层知识库升级 → 业务场景全覆盖 → FABE×MOT 呈现 → 跨服务智能推荐

---

## 一、产品定位回顾

风声 = 经纪人每次客户接触（尤其线下见面）的「见面策展工具」。

- **用户**：经纪人（工具使用者）
- **客户**：经纪人的客户（买房/租房/业主/房东）
- **核心价值**：帮经纪人把一个客户服务明白 → 真实口碑正反馈
- **输出物**：策展包 = 说/带/问/跟，按 MOT 四阶段组织，每条「说」含 FABE 四要素

## 三、V3.0.13：补齐生命周期缺口

### 3.1 业务目标

把购房线和租住线从"签约前-heavy"补成完整生命周期，让经纪人在贷款、整装、租期服务、续约等关键节点也能用风声。

### 3.2 新增场景

| 线 | 新增场景 | 核心推荐工具 |
|----|----------|--------------|
| 购房 | 贷款办理 | 贷款方案对比表 |
| 购房 | 整装服务 | 整装方案推荐卡 |
| 购房 | 资产管理 | 资产跟踪报告 |
| 租住 | 租期内服务 | 租期服务卡 |
| 租住 | 续约谈判 | 续约谈判卡 |
| 租住 | 转租换租 | 转租合规清单 |

### 3.3 引擎改动

- `engine.js` `SCENARIOS` 扩展 6 个新场景
- `generateCuration` 支持新 scenario key
- 新增 subScene 加权：`贷款办理` 命中「资格审查」+2；`租期内服务` 命中「纠纷处理」+2

### 3.4 UI 改动

- `curate-prep` 场景选择器增加 6 个新选项
- 结果页头部显示场景名 + 推荐工具

### 3.5 数据改动

- `entries_slim.js` 新增 ~50 条词条
- 重点补充：B 金融贷款域、H2 整装翻新域、A4 租赁法规域

### 3.6 验收标准

- [ ] 6 个新场景都能在 curate-prep 选择
- [ ] 每个新场景生成策展包时总匹配 ≥10 条
- [ ] 贷款/整装/租期服务场景有专属跟进模板
- [ ] 0 条 buyer 泄漏到租客场景

## 四、V3.0.14：房东/业主线 + FABE×MOT 呈现

### 4.1 业务目标

新增房东出租线和业主出售线，让风声覆盖第四类客户（业主/房东）。同时把引擎输出从「列表式」升级为「FABE 卡片 + MOT 分区」。

### 4.2 新增纵轴与场景

| 纵轴 | 场景数 | 场景链 |
|------|--------|--------|
| 房东出租线 (lease_out) | 4 | 委托出租 → 房屋评估 → 整装翻新 → 租赁托管 |
| 业主出售线 (sell) | 9 | 出售咨询 → 房源评估 → 出售委托 → 房源包装 → 看房接待 → 议价谈判 → 合同签署 → 过户交房 → 资产优化 |

### 4.3 引擎改动

- `AXIS_GROUPS` 新增 `lease_out` 和 `sell` 两条纵轴
- `SCENARIOS` 新增 `lease_out` 和 `sell` 两组配置
- `generateCuration` 输出结构升级：
  - `say` 每条扩展为 `{ feature, advantage, benefit, evidence }`
  - 新增 `mot` 包装层：`{ explore, propose, action, confirm }`
- `clientType` 硬过滤新增 `landlord` / `seller`

### 4.4 UI 改动

- `curate-prep` 纵轴选择器从 2 个（购房/租住）扩展到 4 个
- 场景选择器按纵轴动态渲染
- 结果页新布局：
  - 顶部：MOT 四阶段导航
  - M1 探索：问 + 场景引导话术
  - M2 提议：FABE 卡片（说）
  - M3 行动：带 + 行动步骤
  - M4 确认：跟 + 确认清单

### 4.5 数据改动

- `entries_slim.js` 新增 ~86 条词条
- 重点补充：A1/A2/A3 法规域（业主出售）、F3 评估域、H1/H2/H4 资产管理域
- 字段扩展：新增 `dataRef` / `caseRef`（可为空，找不到写「待补充」）

### 4.6 验收标准

- [ ] 4 条纵轴都能在 curate-prep 选择
- [ ] 业主出售线 9 个场景都能生成策展包
- [ ] 房东/业主场景 0 条 buyer/tenant 内容泄漏
- [ ] FABE 卡片正常展示，E 维度缺失时显示「待补充」
- [ ] MOT 四阶段导航可点击切换

## 五、V3.0.15：知识库全域分类重构

### 5.1 业务目标

把词条从「按交易阶段」组织改为「按知识域」组织，让知识库可扩展、可检索、可复用。同时补齐数据佐证和案例呈现。

### 5.2 知识域架构

- 8 知识域：A 法规政策 / B 金融贷款 / C 学区教育 / D 交易流程 / E 商圈配套 / F 房屋评估 / G 空间美学 / H 资产管理
- 32 子域：每域 3-4 个子域
- 3 支柱：专业知识 + 数据分析 + 案例佐证

### 5.3 引擎改动

- 词条匹配算法升级：除关键词匹配外，增加 `domain` 和 `subScene` 联合过滤
- 搜索结果可按知识域筛选
- 知识页（词典）按 8 知识域重新分类展示

### 5.4 UI 改动

- 知识页新增「知识域」Tab
- 每个词条详情页展示 FABE 四要素 + 三支柱
- 数据/案例缺失时显示「待补充」并支持用户反馈「我需要这个」

### 5.5 数据改动

- `entries_slim.js` 所有词条标注 `domain` 代码
- 新增 ~30 条深度词条
- 为 top 40 强相关词条补充 `dataRef` / `caseRef`

### 5.6 验收标准

- [ ] 知识页可按 8 知识域浏览
- [ ] 每条词条详情展示 FABE + 三支柱
- [ ] top 40 词条至少 50% 有 dataRef 或 caseRef
- [ ] 搜索支持按 domain 过滤

## 六、V3.0.16：跨服务智能推荐 + 长期客户运营

### 6.1 业务目标

从「单次见面策展」升级为「客户全生命周期运营」。根据客户当前状态，自动推荐跨服务机会（如买房后推荐整装、租房后推荐续约、业主出售推荐房源包装）。

### 6.2 核心功能

| 功能 | 说明 |
|------|------|
| 客户生命周期视图 | 客户档案页展示客户当前处于哪个阶段、下一步该做什么 |
| 跨服务推荐卡片 | 根据客户标签和近期行为，推荐整装/托管/资产/置换服务 |
| 自动跟进提醒 | 基于场景时间线（如交房后 30 天、租约到期前 60 天）自动提醒经纪人 |
| 服务效果记录 | 经纪人记录每次跟进结果，形成客户服务的真实口碑数据 |

### 6.3 引擎改动

- 新增 `recommendCrossServices(clientProfile)` 推荐函数
- 客户状态机：根据档案标签判断可推荐的服务类型
- 跟进提醒规则引擎

### 6.4 UI 改动

- 客户档案页升级：生命周期时间线 + 下一步行动建议
- 首页「今日跟进」增强：按时间线排序，显示场景上下文
- 新增「服务推荐」浮层：在策展结果页推荐关联服务

### 6.5 数据改动

- 客户档案 schema 扩展：增加 `lifeCycleStage`、`lastService`、`nextRecommendedService`
- 新增 ~50 条跨服务词条

### 6.6 验收标准

- [ ] 客户档案页显示生命周期阶段
- [ ] 系统能根据客户状态推荐至少 3 类跨服务
- [ ] 跟进提醒按时间线触发
- [ ] 服务推荐有真实词条支撑，不编造

## 七、各版本依赖关系

```
V3.0.13（补齐生命周期）
    ↓
V3.0.14（房东/业主线 + FABE×MOT）
    ↓

    ↓
```

## 八、风险与规避

| 风险 | 影响 | 规避 |
|------|------|------|
| 小眼镜词条交付延迟 | 版本延期 | 每版先骨架后血肉，没词条的场景只显示跟进模板 |
| 数据/案例找不到 | E 维度空虚 | 诚实标「待补充」，不编造 |
| 业主出售线 9 场景太细 | UI 选择器过长 | 支持按纵轴折叠/搜索 |
| 跨服务推荐误触 | 客户反感 | 推荐基于真实客户状态，不强推 |
