# V3.0.12 场景化策展设计 · 房产交易与租赁全场景拆分

> 2026-08-04 · 小豆子 · 基于生哥指令"按业务场景拆分细化，不同场景给不同参谋建议+呈现工具"

## 一、设计目标

将策展引擎从「按客户人生阶段匹配」升级为「按业务场景精准匹配」。经纪人选客户类型 + 见面场景 → 引擎输出该场景专属的参谋建议 + 对应呈现工具。

## 三、引擎改造方案

### 3.1 数据结构变更

**现有引擎输入**：
```javascript
generateCuration({ axisType, axisNodeKey, dimensions, freeText })
```

**新增 scenario 参数**：
```javascript
generateCuration({ axisType, axisNodeKey, dimensions, freeText, scenario })
// scenario: 'first_contact' | 'need_discovery' | 'viewing' | 'mandate' | 'negotiation' | 'contract' | 'handover' | 'after_sale'
```

### 3.3 引擎匹配逻辑变更

```javascript
// 现有逻辑：按 axisNode + dimensions + freeText 检索词条
// 新增逻辑：scenario 注入额外关键词 + subScene 过滤 + 场景化 followup

export function generateCuration(input) {
  const { axisType, axisNodeKey, dimensions, freeText, scenario } = input || {}
  // ... 现有逻辑保持 ...

  // 新增：场景关键词注入
  const sc = SCENARIOS[axisType]?.[scenario]
  if (sc) {
    sc.kw.forEach(k => qKw.add(k))
  }

  // 新增：subScene 过滤加权（非硬过滤，避免空结果）
  if (sc && sc.subScenes.length) {
    // subScene 匹配的词条额外 +2 分
    all.forEach(item => {
      if (sc.subScenes.includes(item.e.subScene)) item.score += 2
    })
  }

  // 新增：场景化 followup（替代通用 followup）
  const followups = sc ? sc.followups : buildFollowups(node, dimensions)

  // 新增：呈现工具推荐
  const recommendedTool = sc ? sc.tool : null

  return { ...result, followups, recommendedTool, scenarioName: sc?.name }
}
```

### 3.4 UI 改造

策展准备页 `curate-prep/index.vue` 新增场景选择器：

```
[客户类型] 购房线 / 租住线
[人生阶段] ①首套 ②改善 ③教育 ...     ← 现有
[见面场景] 首次接触 / 需求深挖 / 带看房源 / 委托签约 / 议价谈判 / 合同签署 / 交房过户 / 售后关怀  ← 新增
[七维关注] 物质安全 / 健康 / 便利 ...  ← 现有
[自由补充] [输入框]                   ← 现有
```

场景选择器为可选项——不选则走现有逻辑（全场景通用），选了则精准匹配该场景。

### 需小眼镜补充的词条（按优先级）
