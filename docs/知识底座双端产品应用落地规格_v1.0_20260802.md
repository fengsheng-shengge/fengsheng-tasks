#### 1.1 场景导航首页

**页面目标**：经纪人选择"我在服务谁"×"走到哪一步"，直达场景词条集合。无需思考"我要查什么"。

**路由**：`/`

**交互规格**：

```
步骤1：选择客户类型（clientType）
  ├─ 买方(buyer)   → 进入步骤2
  ├─ 卖方(seller)   → 进入步骤2
  ├─ 业主(landlord) → 进入步骤2
  ├─ 租客(renter)   → 进入步骤2
  └─ 经纪人(agent)  → 进入步骤2

步骤2：选择阶段（stage）
  ├─ 前期(pre) → 进入步骤3
  ├─ 中期(mid) → 进入步骤3
  └─ 后期(post) → 进入步骤3

步骤3：展示场景结果
  → 按layer分组展示道法术器Tab
  → 每组显示词条卡片列表
  → 默认选中"道"Tab
```

**数据字段映射**：

| UI组件 | 数据字段 | 说明 |
|--------|----------|------|
| 客户类型选择器 | `tags.clientType[]` | 去重后的clientType枚举 |
| 阶段选择器 | `tags.stage[]` | 去重后的stage枚举 |
| 场景分组Tab | `tags.layer` | dao→道 / fa→法 / shu→术 / qi→器 |
| 词条卡片-标题 | `name` | 显示完整标题 |
| 词条卡片-一句话 | `oneLineAnswer` | 截断80字，hover显示全文 |
| 词条卡片-标签 | `entryType` + `severity` | 类型徽章 + 严重度色标 |
| 词条卡片-P角标 | `priority` | P0红/P1橙/P2蓝/P3灰 |
| 词条卡片-客户问 | `consumerQ` | 折叠显示，点击展开 |
| 词条计数 | 聚合计算 | "共 N 条词条" |

**交互状态**：

| 状态 | 表现 |
|------|------|
| 未选择 | 两列选择器均为空，结果区显示引导文案 |
| 选择中 | 选择器高亮当前项，结果区实时刷新 |
| 结果为空 | 显示"该场景暂无词条"+ 推荐相邻场景 |
| 加载中 | 骨架屏 |

**API接口定义**：

```
GET /api/v1/scene/entries

请求参数：
  clientType  string  必选  buyer|seller|landlord|renter|agent
  stage       string  必选  pre|mid|post
  layer       string  可选  dao|fa|shu|qi  不传则返回全部

返回结构：
{
  "code": 0,
  "data": {
    "clientType": "buyer",
    "stage": "pre",
    "summary": {
      "total": 342,
      "byLayer": { "dao": 89, "fa": 78, "shu": 95, "qi": 80 }
    },
    "groups": [
      {
        "layer": "dao",
        "label": "道·心里懂的",
        "entries": [
          {
            "id": "PRE-NEG-RISK-023",
            "name": "定金与订金的区别",
            "oneLineAnswer": "定金有法律约束力，订金没有",
            "entryType": "RISK",
            "severity": "hard",
            "priority": "P0",
            "consumerQ": "我交的定金能退吗？"
          }
        ]
      }
    ]
  }
}
```

**组件规格**：

| 组件 | 字段绑定 | 规格 |
|------|----------|------|
| ClientTypeSelector | `tags.clientType` 枚举 | 横排5个卡片，图标+文字，选中态蓝色描边 |
| StageSelector | `tags.stage` 枚举 | 横排3个胶囊，选中态填充色 |
| LayerTab | `tags.layer` | 4个Tab，带计数角标 |
| EntryCard | id/name/oneLineAnswer/entryType/severity/priority/consumerQ | 卡片高度72px，左侧色条(severity映射)，右侧箭头 |
| EmptyState | — | 插画+文案+推荐链接 |

#### 1.2 场景详情页

**页面目标**：展示某个场景下道法术器四层的完整词条集合，支持逐层深入和快速跳转。

**路由**：`/scene/:clientType/:stage`

**交互规格**：

```
页面结构（从上到下）：
┌─ 场景头部 ──────────────────────────┐
│  客户类型 + 阶段 标签              │
│  统计数字：N条词条 / P0: M条       │
└─────────────────────────────────────┘
┌─ 道法术器四区 ─────────────────────┐
│  ┌─ 道·心里懂的 ─────────────────┐ │
│  │  [词条1] [词条2] [词条3] ...  │ │
│  │  折叠/展开按钮               │ │
│  └───────────────────────────────┘ │
│  ┌─ 法·当场走的 ─────────────────┐ │
│  │  ...                          │ │
│  └───────────────────────────────┘ │
│  ┌─ 术·嘴上说的 ─────────────────┐ │
│  │  ...                          │ │
│  └───────────────────────────────┘ │
│  ┌─ 器·递给客户的 ───────────────┐ │
│  │  ...（默认展开，强调器层）     │ │
│  └───────────────────────────────┘ │
└─────────────────────────────────────┘
┌─ 侧边栏 ──────────────────────────┐
│  筛选器：entryType / severity     │
│  排序：priority / severity        │
│  批量导出按钮                     │
└─────────────────────────────────────┘
```

**数据字段映射**：

| UI组件 | 数据字段 | 说明 |
|--------|----------|------|
| 场景头部-标签 | 路由参数映射 | buyer→买方 / pre→前期 |
| 场景头部-统计 | 聚合计算 | total + P0计数 |
| 道区词条列表 | layer=dao的entries | 按priority排序 |
| 法区词条列表 | layer=fa的entries | 按priority排序 |
| 术区词条列表 | layer=shu的entries | 按priority排序 |
| 器区词条列表 | layer=qi的entries | 默认展开，突出器层 |
| 词条卡片-标题 | `name` | — |
| 词条卡片-一句话 | `oneLineAnswer` | — |
| 词条卡片-核心要点 | `corePoint[]` | 最多显示3条，折叠其余 |
| 词条卡片-类型徽章 | `entryType` | LAW→法条 / PROC→流程 / RISK→风险 / CASE→案例 / STD→标准 / POL→政策 / TERM→术语 |
| 筛选器-entryType | `entryType` 枚举 | 多选 |
| 筛选器-severity | `severity` 枚举 | 多选 |

**交互状态**：

| 操作 | 响应 |
|------|------|
| 点击词条卡片 | 跳转词条详情页（新Tab） |
| 点击折叠/展开 | 该层词条列表折叠/展开 |
| 切换筛选器 | 列表实时刷新 |
| 点击批量导出 | 弹出导出配置弹窗 |
| 器层卡片hover | 显示"预览分享卡"按钮 |

          {
            "id": "PRE-NEG-RISK-023",

| 组件 | 字段绑定 | 规格 |

#### 1.3 词条详情页

**页面目标**：3秒看懂标题+3秒理解结论+3秒知道下一步。可展开深度阅读。

**路由**：`/entry/:id`

**交互规格**：

```
页面结构：
┌─ 3秒区（首屏必须完整可见）────────────┐
│  ┌─ 顶部 ────────────────────────────┐ │
│  │  标题(name)                       │ │
│  │  一句话答案(oneLineAnswer)  大字   │ │
│  │  [类型徽章] [严重度] [层级] [P级] │ │
│  └───────────────────────────────────┘ │
│  ┌─ 客户会问 ────────────────────────┐ │
│  │  "消费者问"：consumerQ            │ │
│  │  "业主问"：ownerQ（条件显示）     │ │
│  └───────────────────────────────────┘ │
│  ┌─ 下一步 ─────────────────────────┐ │
│  │  3条核心要点(corePoint) 列表     │ │
│  │  [查看器层物料] 按钮(qi层词条)   │ │
│  └───────────────────────────────────┘ │
└─────────────────────────────────────────┘
┌─ 深度区（向下滚动展开）──────────────┐
│  ┌─ 详细定义 ───────────────────────┐ │
│  │  def 全文                        │ │
│  └───────────────────────────────────┘ │
│  ┌─ 法条依据 ───────────────────────┐ │
│  │  legalRef 列表 + 外链            │ │
│  └───────────────────────────────────┘ │
│  ┌─ 适用边界 ───────────────────────┐ │
│  │  caveat 全文                     │ │
│  └───────────────────────────────────┘ │
│  ┌─ 关联词条 ───────────────────────┐ │
│  │  同subScene词条 + 同legalRef词条 │ │
│  └───────────────────────────────────┘ │
│  ┌─ 业主卡片（条件）────────────────┐ │
│  │  ownerCard 内容                  │ │
│  └───────────────────────────────────┘ │
└─────────────────────────────────────────┘
┌─ 操作栏（底部固定）──────────────────┐
│  [收藏] [分享] [复制链接] [导出PDF] │ │
└─────────────────────────────────────────┘
```

**数据字段映射**：

| UI组件 | 数据字段 | 显示规则 |
|--------|----------|----------|
| 标题 | `name` | 全文显示，最大48px字号 |
| 一句话答案 | `oneLineAnswer` | 大字高亮，24px，品牌色 |
| 类型徽章 | `entryType` | LAW→法条(紫) / PROC→流程(蓝) / RISK→风险(红) / CASE→案例(绿) / STD→标准(灰) / POL→政策(橙) / TERM→术语(青) |
| 严重度 | `severity` | hard→红点 / medium→黄点 / soft→绿点 |
| 层级标签 | `tags.layer` | dao→道 / fa→法 / shu→术 / qi→器 |
| 优先级 | `priority` | P0→红 / P1→橙 / P2→蓝 / P3→灰 |
| 消费者问 | `consumerQ` | 始终显示，灰色底块 |
| 业主问 | `ownerQ` | **条件**：ownerQ非空时显示 |
| 核心要点 | `corePoint[]` | 最多显示5条，每条前加bullet |
| 查看器层物料 | 关联qi层词条 | **条件**：当前词条非qi层时显示 |
| 定义/描述 | `def` | 完整显示 |
| 法条依据 | `legalRef` | 列表，每条可点击搜索 |
| 适用边界 | `caveat` | 完整显示，黄色背景提示 |
| 业主卡片 | `ownerCard` | **条件**：ownerCard非空时显示 |
| 关联词条 | 关联算法计算 | 同subScene优先，同legalRef次之 |
| 别名 | `alias[]` | 不直接显示，用于搜索匹配 |

**3秒区验收标准**：
- 首屏高度 ≤ 640px（不滚动即可看完）
- 标题字号 ≥ 32px
- oneLineAnswer字号 ≥ 20px
- 核心要点 ≤ 3条可见
- 客户问始终可见

#### 1.4 全量词典页

**页面目标**：团队负责人/培训师批量查阅、筛选、导出词条，支持6维交叉筛选。

**路由**：`/dictionary`

**交互规格**：

```
页面结构：
┌─ 筛选栏（顶部固定）──────────────────┐
│  [客户类型▼] [阶段▼] [层级▼]         │
│  [词条类型▼] [严重度▼] [优先级▼]     │
│  已选条件 Tag ×  清空               │
│  结果数：共 N 条                     │
└─────────────────────────────────────┘
┌─ 列表区 ───────────────────────────┐
│  表头：标题 | 类型 | 层级 | 严重度 | │
│        优先级 | 客户问 | 操作       │
│  ──────────────────────────────── │
│  行1：... | ... | ... | ...        │
│  行2：... | ... | ... | ...        │
│  ...                              │
│  分页：< 1 2 3 ... 100 >          │
└─────────────────────────────────────┘
┌─ 操作栏 ───────────────────────────┐
│  [全选] [批量导出PDF] [批量导出Excel]│
└─────────────────────────────────────┘
```

**6维筛选字段映射**：

| 筛选维度 | 数据字段 | 可选值 |
|----------|----------|--------|
| 客户类型 | `tags.clientType` | buyer/seller/landlord/renter/agent |
| 阶段 | `tags.stage` | pre/mid/post |
| 层级 | `tags.layer` | dao/fa/shu/qi |
| 词条类型 | `entryType` | LAW/PROC/RISK/CASE/STD/POL/TERM |
| 严重度 | `severity` | hard/medium/soft |
| 优先级 | `priority` | P0/P1/P2/P3 |

**批量导出规格**：

| 导出格式 | 内容范围 | 格式说明 |

## 第二部分：搜索系统落地规格

---

### 2.1 匹配字段优先级与权重

| 优先级 | 字段 | 权重 | 匹配方式 | 说明 |
|--------|------|------|----------|------|
| 1 | `consumerQ` | 10 | 模糊匹配 | 客户原话匹配，最高价值 |
| 2 | `ownerQ` | 10 | 模糊匹配 | 业主原话匹配（OWN域词条） |
| 3 | `name` | 8 | 精确+模糊 | 标题是最直接的意图表达 |
| 4 | `alias[]` | 7 | 精确+模糊 | 别名覆盖口语化搜索 |
| 5 | `oneLineAnswer` | 5 | 模糊匹配 | 答案中包含关键词 |
| 6 | `corePoint[]` | 4 | 模糊匹配 | 要点中包含关键词 |
| 7 | `def` | 2 | 全文检索 | 定义中包含关键词 |
| 8 | `legalRef[]` | 2 | 精确匹配 | 法条号精确匹配 |
| 9 | `tags.subScene` | 1 | 精确匹配 | 场景代码辅助匹配 |
| 10 | `entryType` | 1 | 精确匹配 | 类型辅助匹配 |

**综合得分公式**：

```
score = Σ(字段权重 × 匹配度) + 优先级加成 + 严重度加成

其中：
- 匹配度：精确匹配=1.0 / 前缀匹配=0.8 / 包含匹配=0.5 / 模糊匹配=0.3
- 优先级加成：P0=+2 / P1=+1.5 / P2=+1 / P3=+0.5
- 严重度加成：hard=+1 / medium=+0.5 / soft=+0
```

### 2.2 排序算法

**主排序规则**（按优先级依次）：

1. **匹配字段优先级**：consumerQ/ownerQ匹配 > name匹配 > alias匹配 > 其他
2. **匹配度**：精确 > 前缀 > 包含 > 模糊
3. **综合得分**：按2.1公式降序
4. **词条优先级**：P0 > P1 > P2 > P3
5. **严重度**：hard > medium > soft
6. **层级**：qi > shu > fa > dao（搜索场景优先展示可操作的）

**同分处理**：按`id`字典序升序。

### 2.3 智能联想规则

**触发条件**：输入 ≥ 1个字符，防抖300ms。

**联想来源与排序**：

| 来源 | 最大条数 | 排序 |
|------|----------|------|
| consumerQ精确匹配的词条 | 2 | 按搜索频次降序 |
| name前缀匹配的词条 | 2 | 按priority升序 |
| alias精确匹配的词条 | 1 | 按priority升序 |
| 场景推荐 | 2 | 按词条数降序 |

**总计最多7条联想**。

**联想展示格式**：

```
输入"定金"
──────────
💬 "我交的定金能退吗？" → 定金与订金的区别
💬 "定金退还有没有时间限制" → 定金罚则适用条件
📄 定金与订金的区别
📄 定金罚则的适用条件
🏷 定金订金（别名命中）
📍 买方·前期·谈判 (342条)
📍 卖方·前期·签约 (198条)
```

### 2.4 语音搜索ASR→意图识别→词条匹配链路

**完整链路**：

```
步骤1：ASR转写
  引擎：微信小程序同源ASR
  输出：原始文本
  耗时目标：< 1秒（10秒语音）

步骤2：文本预处理
  ├─ 去除语气词：嗯/啊/那个/就是/然后
  ├─ 同义词替换：退定金→定金退还 / 过户费→税费
  ├─ 纠错：订金/定金 自动根据上下文纠正
  └─ 提取关键词：分词 + 去停用词
  输出：处理后的文本

步骤3：意图分类（规则引擎，非ML）
  ├─ 场景意图检测
  │   规则：文本包含[客户类型词] AND [阶段词]
  │   输出：{ intent: "scene", clientType: "buyer", stage: "pre" }
  │
  ├─ 词条意图检测
  │   规则：文本命中 consumerQ/ownerQ/name/alias（模糊匹配≥0.5）
  │   输出：{ intent: "entry", keyword: "定金退还" }
  │
  └─ 模糊意图
      规则：不满足上述条件
      输出：{ intent: "fuzzy", keyword: 原文 }

步骤4：搜索匹配
  复用 /api/v1/search 接口
  参数：q = keyword
  
步骤5：结果截断
  预览：3条（按排序取前3）
  全量：跳转搜索结果页
```

### 入口1：场景导航 → tags匹配 → 词条列表

**路径**：

```
用户选择clientType → 用户选择stage → 系统匹配tags → 按layer分组 → 展示词条列表
```

**匹配逻辑**：

```sql
-- 伪代码
SELECT * FROM entries
WHERE tags.clientType CONTAINS :clientType
  AND tags.stage CONTAINS :stage
ORDER BY 
  CASE tags.layer WHEN 'qi' THEN 1 WHEN 'shu' THEN 2 WHEN 'fa' THEN 3 WHEN 'dao' THEN 4 END,
  CASE priority WHEN 'P0' THEN 1 WHEN 'P1' THEN 2 WHEN 'P2' THEN 3 WHEN 'P3' THEN 4 END
```

**注意事项**：
- 一条词条可能属于多个clientType或stage，匹配时任一满足即命中
- clientType=agent时额外匹配所有词条（agent是泛客户类型）

**覆盖率**：5067条全覆盖（每条词条都有clientType和stage标签）。
