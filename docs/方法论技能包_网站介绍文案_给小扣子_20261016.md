## 二、三张技能卡片（卡片区直接取用）

### 卡片 1 · 管理层汇报定稿法（executive-report）
- **一句话能力**：把素材堆收成可面呈拍板的汇报
- **输入 → 输出**：零散素材 / 多版本文档 → **11 节可拍板汇报 + 最小决策包**
- **适用场景**：向上汇报、方案定稿、要资源 / 要决策的场合
- **给用户带来**：告别"汇报被问倒"，一次面呈即拍板

### 卡片 2 · 商业定位聚焦法（business-positioning）
- **一句话能力**：从"什么都想做"收成"只做谁、不做谁"
- **输入 → 输出**：模糊产品想法 → **锚点表 + 边界表 + 一句话定位**
- **适用场景**：新业务 / 新产品立项开篇
- **给用户带来**：定位聚焦，避免精力发散、什么都做却没做透

### 卡片 3 · 方法论蒸馏四问（method-distill）
- **一句话能力**：把实战经验蒸馏成可复用资产
- **输入 → 输出**：任务复盘 / 经历 → **可复用、可外输的蒸馏卡**
- **适用场景**：每次策划 / 方案 / 复盘 / 评估 / 研究类任务交付后
- **给用户带来**：任务交付不再是终点，经验沉淀得进、找得到、可复用

## 四、每个技能"给用户带来什么"（详述区）

| 技能 | 痛点 | 给用户的价值 |
|---|---|---|
| 管理层汇报定稿法 | 素材散、版本多、汇报被追问就慌 | 收成 11 节结构 + 最小决策包，面呈一次即拍板 |
| 商业定位聚焦法 | 什么都想做，精力发散 | 逼问"谁不符合条件"，写出"不做谁"才叫聚焦 |
| 方法论蒸馏四问 | 任务做完就结束，经验流失 | 4 问成卡，隐性实战变可复用 / 可外输资产 |
