📋 购房准备 · 先搞清楚这 3 件事 经纪人视角
  1. 先问清楚：他买房是为啥？结婚？孩子上学？换大的？还是纯投资？
  2. 把钱算透：首付掏多少？每月还多少？首套二套差几万？税+中介费一共花多少？
  3. 资格和坑先摸清：社保够不够？限不限购？学区对口哪个学校？现在利率多少？
💡 为什么这么做
客户现在最慌的是「我能不能买得起」——你先把数字摆出来，比带看 10 套房都管用
🤖 练一练（AI 模拟客户）
客户问："公积金能贷多少？首套和二套差多少？"
📖 学一学
公积金能贷多少？贷款额度？
首套二套房怎么认定？
学区房怎么查对口学校？
别替客户做「选首套还是二套」的决定——只给数字让他自己选
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
🔍 了解市场 · 先搞清楚这 3 件事 经纪人视角
  1. 先搞清楚他最在意啥：要学区？还是总价不能超？还是一定要地铁口？
  2. 拉真实成交价对比：挂牌价是蒙人的，看真实成交！周边 3 个小区对比一下
  3. 主动说缺点：别只吹好的，每个小区说一个真缺点——有噪音？车位少？学区可能变？
💡 为什么这么做
客户觉得你靠谱，不是因为你懂，是因为你说的话「有根有据」——别拿挂牌价瞎忽悠
🤖 练一练
客户问："要对比周边小区怎么办？这个学区到底怎么样？"
📖 学一学
客户要对比周边小区怎么办？
新盘和二手房选哪个？
客户说要等房价跌怎么办？
别跟客户说「这个学区最好」——只给数据和来源
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
🏠 邀约带看 · 先搞清楚这 3 件事 经纪人视角
  1. 先接住他的抗拒：他说忙，你别逼问什么时候有空，先说「哥您忙我理解」
  2. 给选项别给问题：别说「你啥时候有空」，直接问「周二晚7点？还是周六上午10点？」
  3. 先发点东西过去：户型图/小区实拍视频/报价表，让他在家先看看
💡 为什么这么做
客户不愿出来不是讨厌你，是还没信你——接住他的抗拒比硬逼他管用
🤖 练一练
客户说："最近太忙了，等有空再说吧"
📖 学一学
客户不愿出来看房怎么办？
客户不回消息不接电话怎么办？
客户说随便看看怎么办？
别自己约带看时间——约时间必须真人发消息
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
💬 带看议价 · 先搞清楚这 3 件事 经纪人视角
  1. 先接情绪再谈钱：他说太贵了，你第一句别提价格，先说「哥我理解，这个得慎重」
  2. 给差额给意义：别说「贵20万」，说「贵20万=每月多还X块，但这个学区明年对口Y中学」
  3. 给选项不是逼他走：A 今天定我帮你争取减5万 / B 旁边那套便宜15万但楼层差——让他选不是让他滚
💡 为什么这么做
客户犹豫 = 情绪没接住。先接情绪再给数据，最后那一锤必须真人上
🤖 练一练
客户说："太贵了，回去商量一下。"
📖 学一学
客户说太贵了怎么办？
客户说回去商量一下怎么办？
带看完怎么跟进客户？
情绪安抚必须真人来——AI 可以帮你算数据，但不能替你共情
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
💰 交易安全 · 先搞清楚这 3 件事 经纪人视角
  1. 合同一条一条念：别让他直接签，说「这条是付款时间，这条是违约责任我帮你标红了」
  2. 资金监管说清楚：钱打给银行监管账户，过户完银行自动打给业主——打消他怕被骗的顾虑
  3. 税费算到分 + 时间排死：一张表签字，网签/面签/过户/放款每个节点谁干啥都写清楚
💡 为什么这么做
客户签约那一刻最紧张——你越透明他越敢签。模糊的钱和模糊的时间都是恐惧源
🤖 练一练
客户问："资金监管安全吗？我应该先签还是先交钱？"
📖 学一学
资金监管安全吗？钱打给谁？
二手房合同条款要注意什么？
首套房契税多少？怎么算？
别替客户签合同——合同必须真人口头过一遍
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
🔄 过户交接 · 先搞清楚这 3 件事 经纪人视角
  1. 交房时一项项核对：物业/水电/燃气/户口/维修基金，一项项打勾别漏
  2. 户口迁出写合同里压钱：口头说会迁没用，白纸黑字+压几万块尾款
  3. 过户后别失联：银行放款进度/房管局消息每周说一声，别签完就消失
💡 为什么这么做
交房不是终点——今天这个客户，就是明天给你介绍新客户的人
🤖 练一练
客户问："过户后户口怎么迁？物业交接要注意什么？"
📖 学一学
二手房过户流程是什么？
交房时业主不交钥匙怎么办？
过户延期了怎么办？
别替客户承诺「户口一定能迁」——得看合同写没写
✅ 这个阶段 5 分钟小测验收 → 去测丢单预警 →
