# 风声知识库 · 全域分类重构设计 V3.0.15
> 日期：2026.8.4 | 作者：小豆子 | 状态：待生哥确认

## 一、核心理念

产品三层架构：

```
Layer 3 · FABE × MOT 输出层（见面策展）
    ↑ 场景策展引擎按场景调用知识单元
Layer 2 · 业务场景层（27场景 × 3客户线）
    ↑ 知识域匹配 + FABE展开
Layer 1 · 知识库底座（8域 × 32子域 × 3支柱）
```

**关键变化**：当前 634 条词条按 **交易阶段**（签约前/签约中/签约后）组织，需重构为按 **知识域**（法规/贷款/学区/交易/商圈/评估/美学/资产）组织。每个知识单元内含三支柱：

| 支柱 | 内容 | 对应FABE | 当前字段 | 当前覆盖 |
|------|------|----------|----------|----------|
| **P1 专业知识** | 功能说明 + 优势亮点 + 客户利益 | F+A+B | name/detail + ola/cp + consumerBenefit | 634条 (100%) |
| **P2 数据分析** | 市场数据、统计趋势、量化指标 | E(数据) | `dataRef`（新增） | **0条 (0%)** |
| **P3 案例佐证** | 真实案例、客户故事、标杆对比 | E(案例) | `caseRef`（新增） | **0条 (0%)** |
| **E0 法规依据** | 法律条文、政策文件、行业规范 | E(法规) | `legalRef` | 614条 (97%) |

## 四、数据字段规格

### 4.1 词条结构升级

```javascript
{
  // === 基础标识 ===
  id: "A1-001",              // 域代码+序号
  name: "首套房契税怎么算",
  alias: ["契税", "首套税率"],
  
  // === P1 专业知识 (FAB) ===
  feature: {                  // F: 功能说明
    detail: "首套房90平以下契税1%，90平以上1.5%；二套统一2%（2024年新政）",
    keyPoints: ["90平是分界线", "二套不再区分面积", "2024.9新政统一二套2%"]
  },
  advantage: {                 // A: 优势/亮点
    ola: "首套90平以下只要1%，比二套省一半",
    differentiator: "区分首套二套，按面积阶梯计税"
  },
  benefit: {                   // B: 利益/价值
    consumerBenefit: "买90平以下首套能省0.5%契税，100万的房省5000元"
  },
  
  // === E: 佐证层（三重证据） ===
  evidence: {
    legal: {                   // E0: 法规依据
      legalRef: "《契税法》第3条；财政部2024.9《关于调整个人住房契税的通知》",
      legalLevel: "国家法律"
    },
    data: {                    // P2: 数据分析
      dataRef: "2024年全国首套房平均成交面积89.2平（国家统计局），92%购房者享受1%税率",
      dataSource: "国家统计局2024年房地产统计年鉴",
      dataDate: "2024-12-31"
    },
    case: {                    // P3: 案例佐证
      caseRef: "张先生购89平首套，总价200万，契税2万 vs 二套需4万，省2万",
      caseType: "客户实例",
      caseOutcome: "节省2万元"
    }
  },
  
  // === 分类标签 ===
  knowledgeDomain: "A1",       // 主知识域
  subDomains: ["A3"],          // 辅知识域（可跨域）
  domain: "签约前",            // 保留原有交易阶段（兼容）
  subScene: "资格审查",        // 保留原有子场景（兼容）
  tags: {
    clientType: ["buyer"],     // 适用的客户类型
    scenario: ["first_contact", "contract_signing"]  // 适用的场景
  },
  cq: true,                    // 是否必问
  source: "国家税务总局"         // 来源（当前0%覆盖，需补）
}
```

### 4.2 字段变更对照

| 字段 | 当前 | 变更 | 影响范围 |
|------|------|------|----------|
| `id` | "4-06-02-01" 职业编码 | → "A1-001" 域+序号 | 全量（迁移脚本） |
| `knowledgeDomain` | 不存在 | **新增** | 全量（小眼镜标注） |
| `subDomains` | 不存在 | **新增** | 全量（小眼镜标注） |
| `feature` | `name` + `detail` | 包装为对象 | 兼容（引擎做适配） |
| `advantage` | `ola` + `cp` | 包装为对象 | 兼容（引擎做适配） |
| `benefit` | `consumerBenefit` | 包装为对象 | 兼容（引擎做适配） |
| `evidence.legal` | `legalRef` | 包装为对象 | 兼容 |
| `evidence.data` | 不存在 | **新增 P2** | 全量空白→需补 |
| `evidence.case` | 不存在 | **新增 P3** | 全量空白→需补 |

### 4.3 向后兼容策略

引擎层做适配器，不破坏现有逻辑：
```javascript
// engine.js 适配函数
function adaptEntry(raw) {
  return {
    ...raw,
    // 兼容旧格式
    feature: raw.feature || { detail: raw.detail, keyPoints: raw.cp },
    advantage: raw.advantage || { ola: raw.ola, differentiator: raw.cp?.[0] },
    benefit: raw.benefit || { consumerBenefit: raw.consumerBenefit },
    evidence: raw.evidence || {
      legal: { legalRef: raw.legalRef },
      data: { dataRef: '' },     // 旧词条缺数据
      case: { caseRef: '' }      // 旧词条缺案例
    },
    knowledgeDomain: raw.knowledgeDomain || guessDomain(raw),  // 无标注时推断
    tags: {
      ...raw.tags,
      scenario: raw.tags?.scenario || guessScenarios(raw)
    }
  };
}
```

```javascript
const SCENARIO_DOMAIN_MAP = {

  'renovation':     { buy: ['G','H'], rent: ['G','H'] },
  'after_sale':     { buy: ['A','D','F'] },
  'asset_mgmt':     { buy: ['H','A','B'] },
  'upgrade':        { buy: ['A','B','C','D','E','F','G','H'] },
  // 租赁线
  'tenancy_service': { rent: ['A','D','E','F','G','H'] },
  'renewal':        { rent: ['A','D','F','H'] },
  'move_out':       { rent: ['A','D','F','H'] },
  'sublet':         { rent: ['A','D','H'] },
  'quality_upgrade': { rent: ['E','F','G'] },
  // 房东线
  'entrust_rent':   { landlord: ['A','D','F','H'] },
  'property_eval':  { landlord: ['F','E','H'] },
  'renovation_mgmt': { landlord: ['G','H'] },
  'rental_mgmt':    { landlord: ['A','D','H'] },
  'sell_entrust':   { landlord: ['A','B','D','E','F','H'] },
  'asset_optimize':  { landlord: ['H','B','F'] },
};

// generateCuration 中新增：
function matchByDomain(entries, scenario, axisType) {
  const domains = SCENARIO_DOMAIN_MAP[scenario]?.[axisType] || [];
  if (!domains.length) return entries; // 无场景=全量
  return entries.filter(e => {
    const kd = e.knowledgeDomain || guessDomain(e);
    return domains.some(d => kd?.startsWith(d));
  });
}
```

### 8.2 FABE 展开逻辑

```javascript
function expandFABE(entry) {
  return {
    F: entry.feature?.detail || entry.detail,
    A: entry.advantage?.ola || entry.ola,
    B: entry.benefit?.consumerBenefit || entry.consumerBenefit,
    E: {
      legal: entry.evidence?.legal?.legalRef || entry.legalRef || '[法规依据待补充]',
      data: entry.evidence?.data?.dataRef || '[数据佐证待补充]',
      case: entry.evidence?.case?.caseRef || '[案例佐证待补充]'
    }
  };
}
```

### 8.3 MOT 包装逻辑

```javascript
function wrapMOT(curation) {
  return {
    M1_explore: {
      label: '探索',
      prompts: curation.scenarioConfig?.explorePrompts || curation.ask.map(a => a.q),
      items: curation.ask
    },
    M2_propose: {
      label: '提议',
      tools: curation.scenarioConfig?.tools || [],
      items: curation.say.map(s => ({ ...s, fabe: expandFABE(s.entry) }))
    },
    M3_action: {
      label: '行动',
      steps: curation.scenarioConfig?.actionSteps || [],
      items: curation.bring
    },
    M4_confirm: {
      label: '确认',
      checklist: curation.scenarioConfig?.confirmChecklist || [],
      followups: curation.followups
    }
  };
}
```
