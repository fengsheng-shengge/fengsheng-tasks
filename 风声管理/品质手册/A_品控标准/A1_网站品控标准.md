# A1 网站品控标准

> 版本：v1.0 | 日期：2026.6.23 | 来源：品质手册v2.0+白皮书v1.0整合提炼

---

## 一、功能标准

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 页面可访问 | HTTP 200，响应≤3s | P0，立即修复 |
| 导航可达 | 全站9页面可从首页1次点击到达 | P0 |
| 表单提交 | 数据回传双轨（FormSubmit+Web3Forms）任一可达 | P1 |
| 分享链接 | URL参数正确传递，手机号/姓名正确显示 | P1 |
| 测评闭环 | 从入口→答题→结果→CTA完整可达 | P1 |
| CTA按钮 | 点击跳转目标正确，无死链 | P1 |

## 二、交互标准

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 移动端适配 | Core Web Vitals全绿，无横向溢出 | P1 |
| 页面加载 | 首屏≤2s，LCP≤2.5s | P1 |
| 反馈组件 | 👍👎按钮可用，点击有响应 | P2 |
| 导航固定 | 🏠首页+←返回始终可见 | P1 |
| 表单体验 | 输入有占位提示，提交有加载状态 | P2 |

## 三、VI标准

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 品牌色值 | 7色色板严格一致（见E1品牌色值） | P1 |
| 字体字号 | 4级体系严格一致（见E2字体规范） | P1 |
| 圆角间距 | 卡片8px/按钮4-6px/标签4px | P2 |
| 留白比例 | ≥30%，板块间距80-120px | P2 |
| 对齐规则 | 正文左对齐，仅数据/标语居中 | P2 |

## 四、性能标准

| 指标 | 标准 | 检测方式 |
|------|------|---------|
| LCP | ≤2.5s | Lighthouse |
| FID | ≤100ms | Lighthouse |
| CLS | ≤0.1 | Lighthouse |
| 全页面HTTP | 200 | curl |
| 响应时间 | ≤3s | curl -w |

## 五、SEO标准

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| robots.txt | 存在且配置正确（禁止索引dashboard） | P1 |
| sitemap.xml | 存在且包含全部公开页面 | P2 |
| canonical | 每页设置正确的canonical URL | P1 |
| meta标签 | title/description/og标签完整 | P2 |
| 语义化HTML | 正确使用h1/h2/h3层级 | P2 |
