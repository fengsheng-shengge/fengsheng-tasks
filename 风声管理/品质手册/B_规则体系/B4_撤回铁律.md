# B4 撤回铁律

> 版本：v1.0 | 日期：2026.6.23 | 来源：内容发布品控规范v1.1提炼
> 核心原则：撤回成本远低于问题扩散成本

---

## 铁律：不等确认先撤

发现问题后：
- **≤5分钟**：立即撤回，不犹豫
- **≤2小时**：撤回后修正重发
- **>2小时**：撤回+发更正说明
- 撤回后24h内出复盘报告

## 适用范围

- 网站内容发现错误
- 社媒发布内容有问题
- 品牌定位语/品牌名错误
- 链接不可用/CTA失效
- 任何对外可见的品控问题

## 复盘模板

```
撤回复盘 - [日期]

1. 撤回内容：[什么内容]
2. 发现时间：[何时发现]
3. 撤回时间：[何时撤回]
4. 问题原因：[为什么出问题]
5. 影响范围：[多少人看到]
6. 防止再发：[什么改进措施]
```
