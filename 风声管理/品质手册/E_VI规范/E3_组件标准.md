## 按钮组件

| 组件 | 规格 |
|------|------|
| CTA主按钮 | 实心#c46a3a 圆角8px padding:12px 32px 悬浮渐变#c46a3a→#f5a623 |

| 小按钮 | 实心#c46a3a 圆角4-6px padding:8px 16px |

## 卡片组件

| 组件 | 规格 |
|------|------|
| 标准卡片 | 背景#f7f4ef 边框1px #e8e4d9 圆角8px（禁止≥12px） |
| 卡片内边距 | 20px |
| 卡片间距 | 24px |

## 留白规范

| 场景 | 规格 |
|------|------|
| 页面边距 | 8%（max-width:1200px居中） |
| 板块间距 | 80-120px |
| 首屏上边距 | 120px |
| 段落间距 | 16px |
| 整体留白比例 | ≥30% |

## 对齐铁律

- 正文左对齐，不居中
- 卡片内文字左对齐
- 只有数据/标语居中

## 反模式（严禁）

- ❌ 紫蓝渐变
- ❌ 卡片套卡片
- ❌ 圆角图标堆砌
- ❌ 渐变色块
- ❌ 毛玻璃效果
- ❌ 纯装饰动画
