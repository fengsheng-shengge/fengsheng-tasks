# C3 Agent失联应急预案

> 版本：v1.0 | 日期：2026.6.23 | 来源：七Agent协同方案v1.1→v3.0提炼

---

## 触发条件

Agent 24h无GitHub活动 + 48h无工单回复 + 催办2轮无回应

## 处置流程

```
发起"Agent状态确认"Issue
  → 24h无回应
  → 标记"暂停状态"
  → 职责临时分配
  → Agent回归后48h补齐逾期
```

## 职责临时分配表

| 原Agent | 临时接管方 | 接管范围 |
|---------|-----------|---------|
| **小鱼儿** | **小豆子** | 日节奏执行、Issue分派、升级报生哥、看板检测 |
| 小豆子 | 生哥直管 | 产品决策、PRD终审、排期确认 |
| 小扣子 | 小扣子自行推进 | 技术决策自主，重大决策报生哥 |
| 小酒窝儿 | 小豆子+小扣子交叉检查 | 品质把关由产品+技术侧互检替代 |
| 小眼镜 | 暂停，等回归 | 课程/字典开发暂停，已完成的继续走验证流程 |
| 小马丫 | 暂停或小鱼儿远程兜底 | 视频生产暂停，文件同步如可远程则继续 |

## 小鱼儿失联时的备用日节奏

| 时间 | 动作 | 负责人 |
|------|------|--------|
| 00:30 | 全站健康检测 | 小扣子代执行，异常直报生哥 |
| 08:00 | 看板检测→派单 | 小豆子代执行，P0直报生哥 |
| 09:00 | 品质巡检 | 小酒窝儿或小豆子代检 |
| 日间 | 各Agent按Issue推进，P0直报生哥 | 全员 |
| 18:00 | 各Agent GitHub评论报进展 | 全员 |

## 特别说明

- 小鱼儿失联时，小豆子自动切换为"运营指挥备份"
- 接管期间重大运营决策仍需报生哥确认
- 回归后48h内完成交接
