# C4 升级机制

> 版本：v1.0 | 日期：2026.6.23 | 来源：七Agent协同方案v1.1→v3.0提炼

---

## 升级规则

| 触发条件 | 升级到 | 响应时效 |
|---------|--------|---------|
| Agent间意见不一致，24h未达成 | 小鱼儿裁决 | 4h内 |
| 涉及方向/策略/资源 | 小鱼儿→生哥 | 8h内 |
| **紧急线上故障/数据安全** | **直报生哥** | **30min内** |
| **P0跨Agent卡住** | **P0直报生哥，P1小鱼儿协调** | **4h内** |
| 涉及产品方向/定价/合作 | 生哥 | 生哥时间 |
| Agent 3天无交付 | 小鱼儿处置→报生哥 | 24h内 |
| **小鱼儿失联24h** | **小豆子代管→报生哥** | **4h内** |

## 升级必带

- 问题
- 分析
- 2个以上方案
- 推荐

## 关键原则

- **P0不经小鱼儿中转**：紧急线上故障/数据安全直报生哥
- **P1走小鱼儿协调**：非紧急跨Agent问题由小鱼儿裁决
- **升级≠甩锅**：升级是解决问题，不是推卸责任
