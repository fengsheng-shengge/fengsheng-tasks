# C2 军师机制

> 版本：v1.0 | 日期：2026.6.23 | 来源：七Agent协同方案v3.1提炼
> 灵感：姜胡说"多角度咨询法"——同一个问题问不同AI，像曹操问郭嘉和程昱

---

## 何时启动

- 产品方向/定价/定位等战略决策
- 方案卡在A/B选择，单视角无法裁决
- 生哥主动要求"大家怎么看"
- 新方向启动前（如客户解码器v2、小程序设计）

## 运作流程

```
生哥/小鱼儿发起军师令
  → 指定议题 + 截止时间（默认24h）
  → 被点名的Agent各自独立出观点（不互看，避免从众）
  → 小鱼儿汇总对比表（观点+理由+风险+建议）
  → 生哥拍板
```

## 点名规则

| 议题类型 | 点谁 | 原因 |
|---------|------|------|
| 产品方向/定价 | 小豆子+小眼镜+小酒窝儿 | 产品+业务+品质三视角 |
| 技术架构选型 | 小扣子+小豆子 | 技术+产品可行性 |
| 内容策略/选题 | 小酒窝儿+小眼镜+小鱼儿 | 品控+知识+运营 |
| 运营策略 | 小豆子+小酒窝儿+小鱼儿 | 数据+品质+执行 |
| 新方向探索 | 全员（5Agent各出1条） | 最大视角覆盖 |

## 产出格式

每个军师在Issue评论中回复：
```
🏛 军师令回应 | [议题]
观点：一句话立场
理由：2-3条支撑
风险：我视角看到的坑
建议：如果是你，怎么干
```

小鱼儿汇总为对比表，标注重叠点和分歧点，附推荐方案交生哥。

## 与铁律1的关系

军师机制是铁律1"写的人不验证"的升级版——不只验证，而是同一问题多视角并行产出，让生哥看到全景再拍板。

## 频次

不是每件事都走军师令，只有关键决策才启动。预计每周1-2次。
