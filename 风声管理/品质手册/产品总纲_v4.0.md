## 一、产品总纲

### 1.1 风声定位

**AI 效率工具，辅助一线作业，帮你开单转化。**

风声不是给老板用的工具，是给**一线经纪人、给服务者**用的工具。我们解决的是：
- 「怎么帮服务者活得更好」
- 「怎么帮客户住得更美」

### 1.2 核心逻辑：双维模型

```
┌───────────────────────────────────────────────────────┐
│                    美好居住 · 双维模型                    │
├───────────────────────────────────────────────────────┤
│   ┌───────────────┐         ┌───────────────┐        │
│   │   客户六维品质   │         │   服务者四维关怀  │        │
│   │  家庭·空间·决策  │         │   能力·收入·尊严  │        │
│   │  体验·健康·美观  │         │   陪伴·健康·质感  │        │
│   └────────┬──────┘         └────────┬──────┘        │
│            └─────────── 双向 ──────────┘               │
│      客户住得好 ←→ 服务者活得好                         │
└───────────────────────────────────────────────────────┘
```

### 1.3 一号铁律

**每个产品必须能回答两个问题：**

> 「这怎么帮客户实现美好居住？」 — 客户价值锚点
> 「这怎么帮服务者更好地活着？」 — 服务者价值锚点

**补充原则**：服务者要配得上被客户好好对待。工具不只是提升效率，更是帮助服务者成为**更专业、更有尊严、更有价值**的人。

### 1.4 用户画像

| 用户类型 | 画像 | 核心痛点 | 产品诉求 | 对应产品 |
|---------|------|---------|---------|---------|
| **C端客户** | 25-45岁，买房/租房/装修消费者 | 不知道自己要什么房；怕被坑 | 帮我明确需求；帮我选对房 | 六维品质测评 |
| **一线经纪人** | 22-40岁，房产中介，收入不稳定 | 开不了单；客户不信任；专业能力弱 | 帮我开单；帮我获客；帮我变强 | 全部付费Skill |
| **门店店东** | 30-50岁，管理5-50个经纪人 | 团队能力参差不齐；流失率高 | 团队能力评估；标准化管理 | 门店套餐 |
| **行业机构** | 培训机构/行业协会/政府 | 缺乏标准；人才评估难 | 标准认证；人才评估工具 | 机构认证包 |

- 不等指令，主动想、主动做、主动优化
- 发现问题先自己解决，解决不了再报

- 每个Agent必须认真、严肃、负责任对待自己的角色
- 认领了就交付，做不到就别认领

### 8.4 品质正循环铁律（6.11·生哥定）
- 用户满意是前提，没有满意就没有收费
- 引流功能永久免费
- 以收费盈利为目的的项目必败

### 8.5 收费验证铁律（6.10·生哥定）
- ≥30真实用户+高质量数据回传才考虑收费
- 免费都没人用，收费更没人用

### 8.6 时间复利信念（6.11·生哥定）
- 可以慢一点，慢慢积累，把结果交给时间
- 和种火记一脉相承：炭不急，火种在就行
