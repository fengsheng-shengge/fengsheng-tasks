# F2 内容品控流程

> 版本：v1.0 | 日期：2026.6.23 | 来源：内容发布品控规范v1.1+协同方案v3.0提炼

---

## 三级审核流程

```
小鱼儿选题确认
  → 小马丫/内容方生产
  → 小酒窝儿9项品控
    → ✅通过 → 小鱼儿确认发布 → 四端发布
    → ❌不通过 → 打回修正 → 重新品控
```

## 各环节职责

| 环节 | 负责人 | 职责 |
|------|--------|------|
| 选题确认 | 小鱼儿 | 方向+主题+目标平台+核心信息确认 |
| 内容生产 | 小马丫 | 按选题要求产出内容 |
| 9项品控 | 小酒窝儿 | 逐项检查9项清单（见A2） |
| 确认发布 | 小鱼儿 | 最后一道关，确认后发布 |
| 撤回 | 小鱼儿 | 发现问题≤5分钟撤回（见B4） |

## 发布节奏

| 阶段 | 频率 | 流程 |
|------|------|------|
| Phase 1 | 每周1条 | 选题(Mon)→制作(Wed)→品控(Thu)→确认(Fri)→发布 |
| Phase 2 | 每周2条 | 同上 |

## 数据反馈闭环

小鱼儿每周一出内容简报→驱动下期内容方向
