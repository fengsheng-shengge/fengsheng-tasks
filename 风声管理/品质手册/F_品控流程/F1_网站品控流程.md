# F1 网站品控流程

> 版本：v1.0 | 日期：2026.6.23 | 来源：品质手册v2.0+协同方案v3.0提炼

---

## 日常巡检流程

```
每日00:30 全站健康检测（小鱼儿/小扣子）
  → 异常才报生哥
  → 正常不报

每日09:00 全站品质巡检（小酒窝儿）
  → 四步巡检：链接可访问性→品牌合规→VI一致性→生成报告
  → P0当日修复/P1 24h/P2三天

小鱼儿每日看板检测→分析→派单→晚间闭环
```

## 巡检四步法

| 步骤 | 内容 | 检查项 |
|------|------|--------|
| 第一步 | 链接可访问性 | HTTP状态码+响应时间（超时10秒=失败） |
| 第二步 | 品牌合规性 | 品牌名/定位语/外部引用/产品名/导航链接 |
| 第三步 | VI一致性 | 色值/字体/圆角/间距 |
| 第四步 | 生成报告 | 含健康度评分（满分100） |

## 评分规则

| 级别 | 扣分 |
|------|------|
| P0（页面不可访问） | 每个-20分 |
| P1（品牌合规/VI偏差） | 每个-10分 |
| P2（优化建议） | 每个-5分 |

## 巡检触发条件

- **定期**：每日00:30+09:00
- **变更触发**：每次部署后24小时内
- **反馈触发**：收到异常反馈时立即
- **手动触发**：生哥说"检查网站""巡检""品控"
