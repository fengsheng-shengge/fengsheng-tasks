# F4 产品上线品控流程

> 版本：v1.0 | 日期：2026.6.23 | 来源：协同方案v3.0+白皮书v1.0提炼

---

## 完整流程

```
小豆子写PRD
  → 小扣子技术评估（制约：不可行不开发）
  → 小酒窝儿品质评估（制约：不达标不上线）
  → 生哥确认
  → 小扣子开发
  → 小酒窝儿检核（双签第一签）
  → 小鱼儿终审（双签第二签）
  → 凌晨部署（铁律3）
  → 数据跟踪
```

## 各环节标准

| 环节 | 负责人 | 标准 | 制约权 |
|------|--------|------|--------|
| PRD | 小豆子 | 闭环+Agent化+本地部署三原则 | — |
| 技术评估 | 小扣子 | 2-3天出评估 | 不可行不开发 |
| 品质评估 | 小酒窝儿 | 功能+交互+VI+性能 | 不达标不上线 |
| 终审 | 生哥 | 方向/定价/合作确认 | 没确认不动手 |
| 开发 | 小扣子 | 按代码品控标准执行 | — |
| 检核 | 小酒窝儿 | 上线检核清单逐项通过 | 不通过不打签 |
| 终审 | 小鱼儿 | 品控通过+运营确认 | 双签第二签 |
| 部署 | 小扣子 | 凌晨0点后，全量部署+全页面验证 | — |

## 双签机制

- **第一签**：小酒窝儿检核通过→评论"✅检核通过"
- **第二签**：小鱼儿确认发布→正式上线
- 双签缺一不可

## 变更触发品控

- 每次部署后24小时内触发巡检
- 品控不通过→打回→修复→重新检核
