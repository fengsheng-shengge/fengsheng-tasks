# D2 API Key管理规范

> 版本：v1.0 | 日期：2026.6.23 | 来源：安全审计报告v1.1+白皮书v1.0提炼

---

## 铁律

1. **最小权限原则**：Token仅授予所需最小权限（当前：Cloudflare Pages:Edit）
2. **禁止明文出现**：API Token禁止写入代码/对话/文档
3. **定期轮换**：每季度轮换一次，泄露后立即轮换
4. **泄露即撤销**：发现泄露→立即撤销→重建→审计

## 当前Token清单

| 用途 | 权限 | 存放位置 | 轮换周期 |
|------|------|---------|---------|
| Cloudflare部署 | Pages:Edit | 环境变量 | 季度 |
| 阿里百炼API | 模型调用 | call_jiuwoer.py | 季度 |
| FormSubmit | 数据回传 | HTML表单 | 不适用 |

## 禁止事项

| 🚫 禁止 | 原因 |
|---------|------|
| Token写入代码注释 | 代码可能被公开 |
| Token出现在对话中 | 对话记录可能泄露 |
| Token写入文档 | 文档可能被分享 |
| 多服务共用Token | 一个泄露全部泄露 |

## 事件响应

Token泄露时：
1. 立即在对应平台撤销
2. 生成新Token，设置最小权限
3. 更新所有使用该Token的脚本
4. 审计平台日志确认是否被滥用
5. 通知生哥，记录事故
