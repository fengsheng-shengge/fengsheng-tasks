# D1 网站安全原则

> 版本：v1.0 | 日期：2026.6.23 | 来源：安全审计报告v1.1+白皮书v1.0提炼

---

## 一、架构安全原则

| 原则 | 说明 |
|------|------|
| 纯静态零后端 | 无数据库=无SQL注入；无服务端=无服务端漏洞 |
| 全量部署 | Cloudflare Pages全量替换机制，缺文件=删除页面 |
| 最小权限 | API Token仅授予Pages:Edit权限 |
| 纵深防御 | Cloudflare CDN+HTTPS+DDoS防护多层级 |

## 三、已知漏洞分级

### 🔴 严重级（必须修复）

| 漏洞 | 风险 | 状态 |
|------|------|------|
| 无版本控制 | 变更不可追溯、不可回滚 | 待建Git仓库 |
| 部署无原子性 | 少传文件=全站404 | 待建CI/CD |
| API Token曾泄露 | 旧Token已撤销，新Token最小权限 | ✅已修复 |
| 无备份策略 | 仅依赖Cloudflare 30个Deployment | 待建异地备份 |
| Cloudflare单点 | 账号被盗=全站下线 | 待开2FA |

### 🟠 高危级

| 漏洞 | 风险 |
|------|------|
| 经纪人身份可伪造 | URL参数无验证 |
| 管理看板无真保护 | JS密码可绕过 |
| 无CSP/HSTS | XSS/劫持风险 |
| 无访问监控 | 被篡改无人知晓 |

### 🟡 中危级

| 漏洞 | 风险 |
|------|------|
| 输入无服务端校验 | 恶意注入 |
| 手机号明文在URL | 隐私泄露 |
| 无Rate Limiting | 刷接口 |
| 无robots.txt | SEO+安全双影响 |

### 🆕 AI Agent安全

| 漏洞 | 风险 |
|------|------|
| Prompt Injection | 恶意指令绕过铁律 |
| Agent权限越界 | 可执行任意部署 |
| 知识库投毒 | 错误内容系统性影响 |
| 记忆篡改 | 铁律可被覆盖 |

## 四、安全响应预案

| 场景 | 第一步 | 关键动作 |
|------|--------|---------|
| 网站被篡改 | Cloudflare历史Deployment回滚 | 撤Token+排入口+全量重部署 |
| 域名被劫持 | 联系注册商锁定 | Cloudflare锁DNS+改密码+开2FA |
| API Token泄露 | Cloudflare撤销+重建最小权限 | 审计日志+更新脚本 |
| 数据被滥用 | 冻结相关链接 | 排查范围+72h通知当事人 |
| Agent被操控 | 中止当前操作 | 检查日志+回滚恶意代码+加强过滤 |
