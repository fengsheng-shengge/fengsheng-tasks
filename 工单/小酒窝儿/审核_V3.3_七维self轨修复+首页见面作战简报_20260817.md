## 二、P0 真因与修复（六问）— commit `b032683`

- **依据**：实跑 `buildDimsInsight` 单测，定位 `enabled` 判定 `items.some(i => i.hasBroker)` 仅看经纪人轨。走「简报快速入口」(`genBrief` 只传 `dimSelfScores`、不传 `dimScores`) 时 `selfEval=true` 但 `enabled=false`，客户页雷达图渲染门 `!enabled` 直接返空 → 客户看到空白雷达图 = 线上「七维算不出分」。客户自评问卷 `calcSelfScores` 代码早已存在（非未接问卷）。
- **设计原因**：原判定假设 broker 轨必填，但 self-only 场景（简报快速入口）合法存在，门拦错对象。
- **效果**：仅客户自评场景 `enabled` 变 true，雷达图正常渲染；broker 轨主链路不受影响（双轨/仅 broker 场景结论不变）。
- **解决谁的问题**：C 端客户（自评后看不到画像）、经纪人（画像交付断点）。
- **方式**：仅改 `engine.js` 一处；所有页面雷达图渲染门（`dimsInsight.enabled`）自动受益，无需改页面。
- **验证**：node 单测 6 场景（双轨 / 仅 broker / 仅 self / 空 / 中文 key 口径 / 1-5 分制）均符合预期；self-only 现 `enabled=true`、结论文案正确。
