# 风声 V3.0.5 —— 接通真实词典 + 真实策展引擎 + 客户档案案例参考（A/B/C）

## 一、本次解决的问题（对应真实用户实测四大痛点中的 A/B/C）

用户以真实经纪人身份实测后指出：① 词典是模拟状态；③ 策展包千篇一律没用；② 客户档案空、无意义。本版把**真实资产从二级入口/写死模板拉回主流程**：

### A · 知识页词典：从「模拟网格」改为「真实词条浏览」
- 旧版：词典卡片点开弹 `d.name + ' ' + d.count + '（模拟）'`，全是占位。
- 新版：`import entries_slim.js`（**570 条真实词条**，字段 name/alias/cq/ola/cp/detail/legalRef/consumerBenefit），按真实语义域（签约前/签约中/签约后…）动态聚合+计数；支持关键词检索（名称/别名/必问/话术/误区/详情/利益/法源）+ 域筛选；每条可展开看必问/话术/客户利益/误区/详情，真实法源亮 `✓ 真实依据` 徽标，缺失法源诚实留白。
- 消除知识底座"词典（模拟）"的观感。

### B · 策展主入口：删除写死结果页，切到真实引擎
- 旧版：主 tab「＋ 新建一次策展」走写死表单，结果页含"提前 10 分钟到场""XX 区教育局 2025 入学政策"等占位 → 用户感知"千篇一律、没用"。
- 新版：主 CTA 改为「进入见面参谋 →」直达 `package-curation` **真实引擎 curate-prep**；并从客户档案带 `clientId` 进入（预填纵轴/自由词）。引擎按「双纵轴节点(购5/租4) + 住得好七维 + 自由词」对真实词条打分，动态产出「说/带/问/见后跟进」，每条挂真实法源徽标（绝不编造，缺失标"依据整理中"）。**不同客户/不同输入 → 不同产出**，根治"千篇一律"。

### C · 客户档案：补案例参考 + 闭环空态，变得有意义
- 详情新增「💡 案例参考」区块：按客户角色匹配同类真实案例（兜底前 3），引导"去策展生成专属方案"。
- 空态补"建档 → 见面参谋 → 认知卡沉淀"闭环说明，让"几乎空的模块"有清晰下一步。
