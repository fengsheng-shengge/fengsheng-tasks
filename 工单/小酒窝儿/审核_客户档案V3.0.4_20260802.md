# 客户档案 V3.0.4 —— 根治「真机无法新建」

## 一、本次解决的问题（用户反馈"客户档案依然无法新建"）
经真渲染验证 + 代码核对，定位两类根因：

1. **真机原生 tabBar 遮挡底部"创建客户"按钮**（最可能被感知为"无法新建"）
   - 微信原生 tabBar 是覆盖在 webview 之上的独立原生层；旧版 overlay 底部按钮无避让，真机上被 tabBar 盖住、点不到（H5 里 tabBar 是普通 DOM、z-index 低，所以 H5 能点、真机点不到）。
   - **V3.0.3 已修复**：`.ov-foot` 加 `padding-bottom: calc(10px + 110rpx + env(safe-area-inset-bottom))`，按钮上抬到可见区。
   - 此外页面顶部保留「＋ 新建」常驻按钮（不在 overlay 内，绝不被遮挡），空态也有「立即建立第一个客户」按钮。

2. **保存时异常导致表单不关（观感 = 点了没反应）**
   - `saveForm` 原逻辑：addClient 之后紧跟 markDone / earnPoints，任一步在真机抛错，最后 `showForm=false` 不执行 → 表单卡住、像没建。
   - **V3.0.4 修复**：`saveForm` 整体包 `try/finally`，无论成功失败都关闭表单；并给出明确成功/失败 toast（"客户已创建 · +5 积分" / "创建失败，请重试"）；极端情况下兜底再建一次保证写入。
