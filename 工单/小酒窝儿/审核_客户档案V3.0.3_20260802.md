## 〇、为什么必须 V3.0.3（根因复盘）

用户反馈「客户档案还是不行」。经双线排查，定位两个独立根因：

1. **修复未上 main（最关键）**：V3.0.2 的所有客户档案修复（示例灰化 / 自定义删除 / seedClients 兜底）只在 `feat/mp-v3-curation-prep-20260801` 分支与 PR #211 中；`origin/main`（2229f9e）的 `clients/index.vue` 仍是**旧 broken 版本**（无 seedClients / 无灰化 / 无 focusClientId）。若真机预览包由 main 构建上传，跑的就是坏的旧代码。→ 现已将修复分支 push，`origin/main` 需在合并 PR #211 后才会含修复（见下一步）。
2. **真机冷启动空白 + reload 回弹（真 bug）**：V3.0.2 为修一个「H5 专属」假 bug 加了 `_initialized` 闸门，导致：
   - 冷启动直接落在客户档案 tab 时，要等 App `onShow` 的 200ms 延迟 init，期间空白且不靠 tab 缓存响应式补渲染 → 真机可见空白窗口；
   - seed 判定依赖 `seeded` 布尔的精确反序列化，H5 预览把 boolean 存成 `{"type":"boolean","data":true}` 包装对象导致误判，清空示例后 reload 又塞回示例（回弹）。

V3.0.3 彻底改判据、去闸门、页面 onShow 同步初始化，与启动时序解耦。
