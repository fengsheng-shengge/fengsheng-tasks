## 一、送审范围（新增功能）

1. **见面参谋·策展引擎（确定性，无 LLM）**
   - 输入：客户双纵轴节点（购5：首套/改善/教育/升级/适老；租4：起步/改善/家庭/品质）+ 七维诉求（物质安全/健康/便利/经济/舒适/美观/自在）+ 自由诉求
   - 产出：说 / 带 / 问 / 跟 四类策展项，每项挂真实 `legalRef` 依据徽标
   - 幻觉边界（R2）：仅真实法源挂「依据」徽标；缺依据如实标「依据整理中」；引擎绝不编造法条/数据
2. **策展准备页（分包非 tab 页 `package-curation/pages/curate-prep`）**
   - 客户档案一键带入预填（关系→双纵轴、阶段→节点、备注→自由诉求），降低输入负担（R1）
   - 生成策展包 + 三段式时间轴（见前准备 / 见面执行 / 见后跟进）→ 一键存入认知卡
3. **客户认知复利卡（客户档案页）**
   - 已知偏好 / 决策信号 / 关怀点，初始为空，随真实见面动作沉淀（R5：非积分/兑换外壳，符合虚拟支付规避铁律）
4. **策展页入口升级**
   - 新增「见面参谋（新版）」CTA，旧版表单降级保留（不打断存量用法）
