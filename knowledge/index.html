📋 带看 SOP · 专业方案呈现 + 带看技巧

【带看前 · 准备清单】
  • 🏠 房屋资料三件套（产证复印件 + 业主报价 + 近期成交参考）
  • 👤 客户画像卡（购房动机 / 预算 / 决策人 / 时间线）
  • 🗺️ 路线规划（3 套看房顺序：同小区对比 → 同价位对比 → 升级/降级）
  • 📝 带看确认书（提前微信发送，到店签字）
  • ⚠️ 安全提示（老旧小区电梯 / 高空坠物 / 水电燃气）
高频词条： 带看没签确认书 · VR 带看怎么操作 · 带看安全提示义务
【带看中 · 三步法】
1
破冰（5min）："今天看的这套，业主自住 8 年，保养得特别好"
2
带看（20min）：入户玄关→客厅采光→厨房油烟→卧室隔音→卫生间防水
3
锚定（10min）："您提到孩子明年上学，这套对口学区是..."
【带看后 · 跟进 SOP】
  • ✅ 当天发带看报告（实勘图 + 报价分析 + 竞品对比）
  • 📞 24h 内电话回访（3 问：整体印象 / 最大顾虑 / 要不要约业主）
  • 🆕 3 天内二次带看或逼单
  • 📉 7 天未跟进自动降级
🚫 带看禁忌：不说"这套超好" → 说"3 个亮点 + 1 个需注意"；不说"小区最便宜" → 说"近 30 天成交 8 套，这套排第 3"

🤝 谈判斡旋 · 议价 / 报价 / 砍价 / 客户嫌贵

场景 ① 客户嫌贵（最常见）
客户："这套太贵了，能不能便宜点？"
❌ "已经是底价了" — 关闭谈判
✅ 三步法：
Step 1 共情："我理解，您看了 3 套都超预算，肯定纠结"
Step 2 锚定："业主报 580 万，同户型上月成交 568 万"
Step 3 选项："A 全款谈 570 万；B 公积金拉长周期让业主让价"
场景 ② 业主不肯降价
业主："这个价已经是小区最低了"
✅ 破局："报价合理我同意。但客户首付能出 60%，您要不要考虑全款到账快的优势？"
场景 ③ 竞品对比
"隔壁小区比这便宜 20 万"
✅ 回应："隔壁便宜 20 万，但 3 个差异：① 隔壁是老破小没电梯；② 这套对口学区重点；③ 隔壁物业费 4.5 元/平，这套 2.8。您算算账——"
场景 ④ 谈佣金
"中介费能不能打折？"
✅ 回应："佣金公司规定，但我可以帮您争取 3 个增值：① 免费代办过户；② 免费评估贷款额度；③ 后续续租/出售优先服务。"
🚫 谈判禁忌：不了解客户底牌就开谈；不让业主和客户直接私聊；口头承诺任何条件 → 微信文字确认！

✍️ 签约协办 · 网签 / 资金监管 / 过户 / 税费

Step 1 签约前 · 资质核验（必做！不做 = 你担责）
  • 👤 买方：身份证 + 购房资格（社保/个税连续缴纳）+ 征信报告
  • 🏠 卖方：房产证 + 身份证 + 银行结清证明（无抵押）
  • 🔒 房屋：无查封无冻结（查档）+ 共有人同意出售证明
⚠️ 红线：客户没购房资格促成签约 = 你要担责！无证带看签合同 = 被查处罚款！
高频词条： 没购房资格要担责吗 · 无证带看会怎样 · 签约前资质核验流程
Step 2 签约中 · 合同三审
①
一审：买卖双方身份信息（身份证号/联系方式/紧急联系人）
②
二审：核心条款（成交价/首付比例/贷款方式/交房日期/违约责任）
③
三审：附件清单（家具家电/装修现状/物业费结清/户口迁出）
Step 3 网签 + 资金监管
  • 📝 网签：去房管局官方系统签示范合同（不能自己打印！）
  • 🏦 资金监管：首付/贷款进监管账户，过户完成后自动到账
Step 4 过户 + 税费
  • 💵 买方缴税费：契税 1-3% / 个税 20% / 增值税 5.3%（满二免）
  • 🔑 卖方配合过户：到场签字 / 授权委托
  • 📄 领新产权证 + 水电燃气过户
🚫 签约禁忌：不让客户看完整合同就催签；合同空白处事后补填；替客户保管身份证/房产证原件！

🧑 服务跟进 · 入住 / 维修 / 续租 / 老客复购

成交后 100 天跟进计划
📦 Day 1-7 · 交付期
    交房当天：陪验房 + 拍照留底 + 交接钥匙水电卡
    3 天内：水电燃气过户 + 物业报备
    7 天内：入住温馨回访
🏠 Day 8-30 · 适应期
    第 14 天：深度回访 — 有没有遇到问题？
    第 28 天：推荐社区服务 — 附近幼儿园/医院/超市
🌱 Day 31-100 · 稳定期
    第 60 天：需求变化跟进 — 工作变了？需要换房？
    第 90 天：老客维护 — 介绍新朋友？推荐出售时机？
老客复购 · 5 个跟进触发信号
🎂 朋友圈晒娃/结婚照 → 升级换三房时机
✈️ 朋友圈发工作变动/城市迁移 → 可能卖房
📉 政策利好（降息/落户放宽）→ 推送买房机会
🎁 老客生日/乔迁/节日 → 个性化问候
📈 小区成交新高 → "你家小区最近涨了 8%"
🚫 服务禁忌：成交就消失 — 售后是口碑来源；节日群发祝福 — 个性化才有温度；催老客卖房 — 专业建议 > 销售
