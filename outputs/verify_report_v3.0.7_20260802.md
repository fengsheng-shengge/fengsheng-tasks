## 四、用户如何提审（无需小扣子）

1. 解压 `outputs/mp-weixin-v3.0.7-20260802.zip`
2. 打开**微信开发者工具** → 导入项目 → 选择解压目录（或本仓库 `fs-mini-program/dist/build/mp-weixin/`）
3. 编译无误后 → 右上角「上传」→ 版本号填 `3.0.7` → 项目备注「V3.0.7 真实词典+真实策展+客户档案新建+真实测评」
4. 上传后到 mp.weixin.qq.com 后台「提交审核」→ 审核通过即发布正式版
5. **建议先点「真机预览」扫码自测**（H5 验证是模拟层，真机最终把关；功能逻辑已真渲染验证 13/13）
