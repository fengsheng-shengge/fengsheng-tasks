## 二、需用户真机闭环（诚实边界）

本沙箱**没有微信开发者工具**，以下只能由你在真机/开发者工具完成：

1. **微信开发者工具 → 导入** `dist/build/mp-weixin`（即提审 zip）→ **真机预览**，确认：
   - 客户档案 tab → 点「＋ 新建」→ 浮层全屏弹出 → 填「称呼/全名」→ 点「创建客户」→ 卡片 +1
   - Console **无** `module ... is not defined` 类报错
2. **版本确认（新增，消除歧义）**：打开「我的」页，底部应显示 **「风声 v3.0.7」**。
   - 若显示不是 3.0.7 → 手机跑的是旧包，**必须重新上传/预览最新 zip**，之前的"不行"即源于此。
