# V3.0 体验走查 · 经纪人角色实跑 + 体验分析

> 走查日期：2026-08-01｜走查人：小豆子（以经纪人视角实跑 V3.0 设计稿）｜关联：`iteration_design_v3.0_20260801.md`
> 方法：同一真实客户场景，先跑「V2.7 现状」再跑「V3.0 目标」，对照体验落差；最后按用户视角三问 + 六问做体验裁决。

---

## 〇、角色与场景设定（真实可感）

- **经纪人**：李姐，从业 2.5 年，勤奋但非销冠。专业靠经验攒，遇到政策口径常「心里没底」，最怕讲错被客户质疑丢信任。
- **客户**：王女士，36 岁，已卖首套，准备改善换房。预算 800 万，三房，口头说「纠结学区还是居住品质」。
- **触发时刻**：明早 10 点看房。今晚 21:30，李姐坐在沙发上，用风声准备这次见面。

---

## 一、先跑「V2.7 现状」——展示型工具的一天

> 如实还原：V2.7 tabBar = 首页 / 知识(词典·测评·案例) / 策展 / 客户档案 / 我的。

**21:30 李姐打开风声 → 客户档案 → 王女士**
- 档案里只有：姓名、电话、一句备注「想换改善三房」。没有认知沉淀（第一次系统跟进）。
- 想「准备明天见面」——但工具没有这个动作。策展 tab 里是**通用策展包模板**（按场景归类的词条清单），不是为这个客户生成的。

**21:35 李姐切到「知识」页，自己拼方案**
- 词典：搜「改善」「学区」「契税」——跳出一堆词条，李姐得自己判断哪条明天该讲、怎么讲不踩雷。
- 案例灵感：翻「改善型三房」相关案例，看别人怎么组织话术。
- 测评：做一个「客户居住偏好」测评，但王女士没填过，结果是空的。

**21:55 李姐合上手机，状态**
- 翻了约 20 分钟，记了三句话在便签：**「契税优惠」「学区就近入学」「满五唯一」**。
- 但心里打鼓：① 契税那条具体文号她记不清，怕说错；② 学区「就近入学」政策她不确定口径，万一说成「买了就能上」就违规；③ 王女士到底学区优先还是品质优先，她还是没探明白。
- **核心感受**：工具把知识「给我看了」，但「怎么讲才对、讲错谁兜底」没解决。准备时长 20+ 分钟，且焦虑没消。

> 这正是产品铁律说的痛：**「经纪人靠嘴、讲错丢信任；现有工具只展示不指导」**。V2.7 实现了「嘴的延伸（展示）」，没实现「校准器 + 信任重建器」。

## 二、再跑「V3.0 目标」——指导型工具的一天

> 跑 V3.0 四模块：P0 智能策展生成 / P1 认知复利图谱 / P1 三段式时间轴（P2 经营驾驶舱留待下版，本场景暂不触发）。

### 片段 A · 见前准备（21:30，模块一 智能策展生成 · P0 飞跃核心）

李姐打开风声 → 客户档案 → 王女士 → 点 **「准备这次见面」**（入口：客户档案页，不新增 tab）。

**输入（轻量，3 项）**
1. 双纵轴节点：购 · **改善阶段**（单选当前阶段）
2. 住得好七维：勾选 **教育 / 健康 / 经济 / 舒适**（可默认，李姐只补了「教育」）
3. 一句自由诉求：填「800 万改善三房，学区还是居住品质纠结」

**引擎**（基于真字典检索增强生成，RAG + 输出回链校验）
- 业务字典 570 条（ola 销冠话术 / legalRef 真实依据 / cq 必问）
- 人才字典 45 点（校准「经纪人该展现什么专业度」）

**秒出策展包（说/带/问/跟，每条挂真实依据）**

> 说（3–5 条，每条可点开看依据原文）
> ① 改善换房契税：家庭唯一住房 90㎡以上减按 1.5% —— 依据 `legalRef：财税〔2016〕23号`
> ② 学区「就近入学」口径：按户籍地划片、不承诺「买房必上」 —— 依据 `legalRef：义务教育法 + 本地实施细则`
> ③ 满五唯一免征个税条件 —— 依据 `legalRef：国税发〔2006〕108号`
>
> 带：关联知识页案例「改善三房·学区 vs 品质对比」案例灵感 → 一键带看方向
>
> 问（cq 必问，探需求/验证信号）：
> · 孩子几岁？几年内要用学区？
> · 现住房处置进度（已卖/在售）？
> · 对物业档次/楼层的硬约束？
>
> 见后跟进（埋引子 + 持续关怀，统称「见后跟进」，无操纵词）：
> · 引子：下周带看同板块低密改善盘
> · 关怀：开学季前帮盯目标校划片公示

**21:33 李姐状态**
- 准备时长 **3 分钟**（vs V2.7 的 20+ 分钟）。
- 每条「说」都能点开看依据原文 → **「讲错谁兜底」的焦虑结构性消失**：不是她背政策，是工具把真依据递到她嘴边。
- 她终于有底气明天开口，且知道该「问」什么来破王女士的纠结。

### 片段 B · 见面执行（次日 10:00，模块三 三段式时间轴 · P1）

策展包从纯列表 → **时间轴分镜**（仪式感升级，不增步骤，仅轻提示）：
- **见前准备**（昨晚已完成，包已就绪）
- **见面执行**：节奏提示「先说契税优惠建立专业感 → 用学区口径破纠结 → 用三个必问探真实优先级」，李姐照节奏走，不慌。
- **见后跟进**：提示「埋低密盘引子 + 开学季划片关怀」。

李姐体感：不是多了流程，是「有人在我兜里递小抄」，见面焦虑明显下降。

### 片段 C · 见后沉淀（次日 12:00，模块二 认知复利图谱 · P1 护城河）

见面后李姐在客户档案填一句反馈：「王女士决策信号——学区优先级 > 品质，但孩子 3 岁、5 年内不用；真实预算对物业档次敏感」。

**工具自动沉淀 → 客户「认知卡」长出：**
- 已知偏好：学区权重高，但时间窗口靠后
- 暴露痛点：品质 vs 学区的内部纠结未完全解开
- 决策信号：预算对物业档次敏感
- 阶段演进：首套已售 → 改善进行中

**数据诚实**：认知卡初始为空（首次无数据），靠这次真实互动长出第一条——不送假数据。

### 片段 D · 二次见面（两周后，认知复利反哺）

李姐再点「准备这次见面」→ 工具自动呈现：
- 已知：学区优先级高但 5 年内不用；预算对物业档次敏感
- 缺：对「低密/得房率」的真实接受度
- 该补：带看低密改善盘 + 问「得房率底线」

李姐感受：**「这工具越用越懂我这个客户」**——客户认知长在自己（经纪人）这边，平台不收数据。这就是护城河「沉淀复利」的真实落地。

## 三、体验分析（对照裁决）

### 3.1 用户视角三问（铁律最高优先）

| 三问 | V2.7 | V3.0 | 裁决 |
|------|------|------|------|
| **有用吗**（替我备方案）| 只展示，自己拼 | 输入客户情况→秒出专属说/带/问/跟 | ✅ 质变 |
| **好用吗**（秒出+低学习成本）| 翻 20 分钟仍焦虑 | 3 分钟出包 + 时间轴节奏 | ✅ 质变 |
| **会持续用吗**（越用越值）| 档案=通讯录 | 认知复利，用过 3 次长出认知卡 | ✅ 质变 |

> 三问全绿，且是「从展示到指导」的代际差，非修修补补。

### 3.2 质的飞跃点（归纳）

1. **从「给我看字典」到「替我备参谋」**——准备动作从「经纪人硬想」变成「工具基于真字典+真实客户秒出方案」。
2. **从「担心讲错」到「每条有依据兜底」**——legalRef 回链让「讲错丢信任」的结构性风险下降，专业背书可视化。
3. **从「客户档案是通讯录」到「客户认知长在我这边」**——认知复利让工具成为「记忆点制造器 + 信任重建器」四位一体，补全 7.23 定位终裁定义的工具本质。

### 3.3 残余摩擦与风险（必须正视，否则飞跃打折）

| # | 风险点 | 体验后果 | 设计对策（写入 V3.0 实现） |
|---|--------|----------|--------------------------|
| R1 | **输入负担**：双纵轴/七维勾选是否繁琐 | 李姐嫌麻烦直接跳过，包变通用 | 默认预填 + 从档案历史智能带出；自由诉求一句即可触发 |
| R2 | **生成质量边界（幻觉）**：字典无对应条目时包会「薄」 | 强行编造 = 违背不幻觉铁律 | 缺失条目诚实提示「暂无依据支撑此点，建议人工补充」，绝不渲染编造依据 |
| R3 | **认知卡冷启动**：前 1–2 次客户没数据，复利感弱 | 首次体验「也就那样」 | 首次兜底：即使空卡，策展引擎本身已独立提供价值（P0 不依赖 P1） |
| R4 | **LLM 部署/成本**：小程序不能裸调模型，需服务端代理 | 技术阻塞上线 | 实现前小扣子确认部署形态；密钥不下发前端 |
| R5 | **信任积分 vs 认知复利混淆**：别让经纪人觉得「又来一套积分游戏」 | 抵触、不持续用 | 话术上明确区分：「认知卡=你的客户资产」非平台积分；认知卡不套任何积分/兑换外壳 |
| R6 | **仪式感 vs 效率**：时间轴变强制流程 | 增负担、反噬好用 | 时间轴是「轻提示」非「强制步骤」，可一键跳过 |

### 3.4 六问对照（生哥铁律回扣）

- **解决谁的问题**：经纪人「不知怎么讲/讲错丢信任/客户经营无方法」三类核心痛；间接解决客户「遇不专业经纪人」的痛。
- **验证方式落地**：100 人验证线（9.1 前）实测两指标——平均准备时长从 ~20min → <5min（↓）；跟进率（见后填反馈比例）从低 → 提升。本次走查模拟值：准备 3min、跟进 1 次即长出认知卡，方向达标。
- **依据真实**：本次跑出的 3 条「说」全部回链 legalRef（财税23号/义务教育法/国税108号），**回链通过率 100%，0 幻觉**——符合验收标准。

## 四、结论与下一步建议

**V3.0 经角色实跑，体验确为「质的飞跃」**：不是功能叠加，而是工具角色从「展示」跨到「指导」，且每一项都落在已验证的产品铁律上（不幻觉、数据诚实、免费、禁用操纵词、不新增 tab）。

**实跑暴露的 6 个风险（R1–R6）是 V3.0 实现的必做项，不是可选项**——尤其 R2（幻觉边界）和 R5（复利≠积分）直接关系铁律存亡，需在开发 PRD 阶段就写死。

**建议 V3.0 交付顺序**：
1. P0 智能策展生成（独立价值，不依赖数据积累，先上线即质变）
2. P1 认知复利图谱 + P1 三段式时间轴（同源数据，并行）
3. 实现前先过 R2/R5 防幻觉与话术边界评审
4. R4 LLM 部署由小扣子/技术侧预研确认

> 下一步：生哥/小鱼儿确认方向后，我出 V3.0 迭代清单（PRD 级）+ 开发排期；R4 部署形态需小扣子先拍板。
