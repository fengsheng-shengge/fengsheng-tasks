方案 B · 上下行 × 箭头映射（简洁明了）⭐ 推荐
在阶段 Tab 和能力画像之间，插入一张消费者→能力映射表。每一行清晰表达"消费者在 X 阶段 → 经纪人需要 Y 能力"。双主体语义色：金色=消费者侧，墨绿=服务者侧。

✅ 优点：一张表看懂底层逻辑、每行独立可扩展、主次关系清晰（深色=核心能力，浅色=辅助能力）
❌ 缺点：静态展示，没有交互（用户不会主动去看完整张表）
方案 C · 交互联动（Hover 高亮 + 点击锁定）
不新增大板块，而是让现有两块东西互动起来：鼠标 hover/点某个"购房阶段"，下面对应的能力维度就高亮。反过来点某个能力维度，上面哪些阶段需要它也联动高亮。

✅ 优点：零新增视觉负担、利用用户已有的浏览行为、交互即理解（"哦，原来带看议价主要靠谈判和洞察"）
❌ 缺点：需要用户 hover 才能看到、不会主动理解"全链路映射"、适合做补充层而不是主视觉
🎯 推荐：B + C 组合
用 方案 B（映射表） 作为首次引导——在工作台首次打开时显示一次，点击"我知道了"之后折叠成一行小标题。用户第二次进来直接看到已有的筛选 Tab + 能力画像，但加了 方案 C（交互联动）——hover 阶段 Tab 时能力画像联动高亮。

这样既传达了"我们的能力体系是从消费者需求导出的"这个核心产品故事，又不增加长期视觉负担。
