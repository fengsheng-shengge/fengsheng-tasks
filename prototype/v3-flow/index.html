客户说"太贵了"怎么办？
带看谈判 CAP-SKILL-101 4 个话术版本 · 4 个相关工具
›
先共情接住情绪 → 给客观数据支撑 → 引导说出真实顾虑（真缺钱？觉得不值？想压价？）
版本 A · 理性客户
讲数据 · 讲对比
"张哥您说的隔壁小区 480 万那套我知道——6 楼没电梯、朝北、满五唯一还差 2 个月。咱们这套中间楼层、南北通透、业主急售价格已经让了 15 万。我觉得主要是位置您可能觉得偏了点？要不我给您对比下两个小区近 3 个月的成交记录？"
版本 B · 感性客户
先共情 · 拉近距离
"李姐我特别理解您的感受，520 万确实不是小数，换我买房也得掂量掂量。这几天带您看下来，感觉您对这套是真心喜欢的——是不是主要是价格这块儿有点犹豫？您跟我说个实在数，我拼尽全力帮您争取。"
版本 C · 爱面子客户
给台阶 · 降焦虑
"张哥我跟您说句实在的，这价格真不贵——这个户型在望京板块真没有比这套性价比高的了。您能看中这套眼光真不错。这样，您今天给个痛快话，我帮您跟业主砍到 510 万，差的那 10 万我来贴点，咱就把合同签了。"
版本 D · 刚需客户
直接 · 帮想办法
"王哥我明白，首付确实压得紧。520 万这套是好，但咱们能不能退一步——旁边那个小区 490 万的两居室您考虑吗？楼层差点、装修旧点，但总价差 30 万，首付能少掏 9 万多。我下午就能带您过去看。"

需求洞察 CAP-SKILL-202 3 个话术版本
›
肯定客户（买房是大事）→ 挖真实顾虑（您跟我说我好准备材料）→ 留钩子（您老婆最关心什么？）
版本 A · 真要商量
支持 · 帮忙准备
"应该的哥！买房是大事，肯定得跟老婆商量。您跟我说，她主要关心什么？我好准备点材料——学区？还是户型？或者我帮您拍几张房子细节照片，您回去给她看看？"
版本 B · 假商量
点破 · 给安全感
"哈哈张姐我懂，'跟家人商量'有时候是'我自己还没想好'对吧？没事，您跟我说实话——是价格这块儿觉得贵了？还是房子本身有哪块不满意？我好帮您想想办法。"
版本 C · 其实不喜欢
给台阶 · 换方向
"应该的李姐！您回去好好想想。不过我猜您心里可能也有想法了——您是觉得这套哪块不太合适？楼层？还是装修？您跟我说，我好给您找找别的方向。"

首套房契税多少？怎么算？
专业方案 CAP-SKILL-301 3 个话术版本
›
分情况列清楚 → 给计算公式 → 附法条依据（怕算错担责）
版本 A · 首次购房完全不懂
耐心 · 一步步
"姐我给您算一下——首套房 90 平以下契税 1%，90 平以上 1.5%。咱们这套 89 平，网签价 450 万，契税就是 4.5 万。满五唯一免增值税和个税，税费总共就 4.5 万。我发张计算表给您，上面有法条依据，放心。"
版本 B · 有经验要数字准
直接 · 给数 · 给依据
"王哥，这套 89 平，满五唯一，您首套：契税 4.5 万（网签价 450 万 × 1%），增值税 0，个税 0。总共 4.5 万。依据京财税〔2016〕213 号文，首套 90 平以下按 1%。需要我把计算表发您吗？"
版本 C · 业主问卖房要交多少
替业主算账
"哥您这套满五唯一，卖房只交一个印花税，网签价的万分之 5，也就是 2250 块。其他没有了。要是找中介挂牌，中介费是成交价的 2%，比如卖 520 万就是 10.4 万。"

交易履约 CAP-SKILL-501 2 个话术版本
›
明确放银行不是中介 → 讲清楚监管账户是什么 → 画清楚钱的流转路径 → 给法条依据
版本 A · 特别谨慎客户
打消顾虑 · 讲流程
"李姐您放心！监管的钱是放在银行监管账户里的，不是中介公司账户——我一分钱都碰不到。流程：您首付打监管账户 → 银行冻结 → 过户完成 → 银行自动解冻给业主。全程有北京住建委的监管办法管着，您随时可以去银行查。"
版本 B · 半懂不懂
画图式讲 · 简单明了
"王哥简单说：您 → 银行监管账户（冻结）→ 过户完成 → 银行自动打给业主。我和中介全程碰不到钱。监管账户密码只有银行知道，这个是住建委强制要求的，不是我们能改的。"
