📐 五层权重与评分方式

层级 名称 权重 评分方式 数据源 人社映射
Layer 1 📚 专业知识 25% measurement（客观可测） exam 硬7维答题分 《经纪专业基础》
Layer 2 🛠️ 操作技能 + 🤖 AI 工具使用 40% ↑ measurement（客观可测） care-test × 40% + practice × 30% + AI使用率 × 30% 《经纪业务操作》· DIM-7 数字化协同
Layer 3 💞 通用技能 25% judgement（主观可验证） 软5维平均分 职业能力第(一)条
Layer 4 🧩 案例分析 10% judgement（高级专属） 硬方案+履约（临时）· 预留开放题/LLM 高级经纪人综合评审
Layer 5 📖 持续学习 门槛 门槛条件（不参与加权） 课程完成率 + 继续教育学时 3 年 ≥ 90h 登记要求

⚖️ 综合分公式 + 红线机制

综合分 = Layer1×0.25 + Layer2×0.40 + Layer3×0.25 + Layer4×0.10
🚨 红线：if SOFT-4 职业素养 < 50 → 综合分 = min(综合分, 50) （一票否决）

📚 术语解释

  • measurement（客观可测）：可通过标准化考试/场景完成度直接量化，不同考官评分一致
  • judgement（主观可验证）：需要专业判断，但可通过 peer review / 真实行为验证
  • weighting（权重）：由 WorldSkills 行业专家和企业共同建议各部分的相对重要性
  • 红线否决：服务伦理是不可逾越的底线——SOFT-4 < 50 即使其他维度满分，综合分也封顶 50

🔍 当前局限（已知）

  • Layer 4 案例分析用硬方案+履约两个维度平均分临时替代，不是真实案例评审。预留方案：exam 加开放题（用户写决策理由）+ LLM 批改 + 真实业绩数据接入
  • Layer 2 场景应对力只看"完成率"不看"质量"——用户乱选一通也算完成。预留：practice 存每轮选择正确率
  • 红线否决只有答题分验证，没有真实红线事件记录。预留：peer review 红线记录（如"被同事举报承诺最低折扣"）
  • 权重统一 25/40/25/10，未按行业/角色差异化。预留：豪宅经纪人 → Technical 权重更高；租赁经纪人 → Generic 权重更高
