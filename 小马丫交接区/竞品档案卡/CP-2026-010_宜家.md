## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 家居产品销售（核心）+ 餐饮（瑞典餐厅/小食店，占营收约5%）+ 线上渠道（官网/天猫/京东） |
| 佣金/收费结构 | 不涉及平台佣金 — 宜家为自营零售商，收入=产品售价-成本；安装服务单独收费（约产品价10%-15%）；配送费部分区域免费、偏远地区另计 |
| 数据透明度 | 高 — 所有产品明码标价（线上线下一致）、尺寸/材质/价格标签清晰、部分产品公示成本构成；但适老化产品线占比数据不公开 |
| 服务边界 | 做：家居零售（家具/家居用品/装饰品）、餐饮、送货安装、旧家具回收、部分城市"全屋设计"服务；不做：定制家具（衣柜内部结构半定制除外）、家装施工、辅具租赁、适老化改造施工 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 180天无理由退换（需保留包装/完好）；质保：一般产品1-5年（沙发框架5年/纺织品2年）、厨房电器5年；投诉渠道：门店售后、官网客服、12315、黑猫投诉 |
| 用户投诉集中点 | 平板包装+自行组装（动手能力要求高、老人/独居者困难）；安装收费高（衣柜安装费可达总价20%以上）；部分产品耐用性不足（抽屉滑轨易损/板材寿命短）；偏远地区配送慢/大件易损坏；售后服务流程繁琐（需购买凭证/退换需自行运输到门店） |
| 优势维度 | 全球供应链规模效应→低价策略（"毕利书架"¥599远低于竞品）；北欧简约设计风格（差异化明显）；场景化体验营销（样板间+餐饮+儿童游乐区）；明码标价透明度高；会员体系覆盖3000万+用户 |
| 弱势/争议点 | 适老化产品线薄弱（2023年"安心在家"仅10余款，远不及日本骊住/松下）；平板组装门槛高→排除老年及动手能力弱群体；售后效率低（维修周期长/客服排队久）；本土品牌（林氏木业/源氏木语）价格竞争加剧 |
