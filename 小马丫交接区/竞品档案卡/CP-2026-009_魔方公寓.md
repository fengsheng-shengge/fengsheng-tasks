## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 租金差（拿房成本占收入50%-60%）+ 服务费（固定200-500元/月或租金5%-8%）+ 增值服务（保洁/维修/搬家）+ 企业定制宿舍管理费 + 轻资产输出（品牌授权/运营托管，收取营收3%-5%管理费） |
| 佣金/收费结构 | 租金：上海单间¥4000-12000/月（按地段/房型/子品牌分层）；服务费：固定金额或租金5%-8%；押金：1-2个月租金；品牌分层：魔方公寓（中高端）→9号楼（企业定制）→魔尔（高端服务式） |
| 数据透明度 | 中 — 租金公开透明、合同服务费明细可查；但不公布出租率（仅对外宣称≥90%）、不公布单店净利润、不公布装修成本折旧详情 |
| 服务边界 | 做：集中式公寓运营（整栋改造→标准化单间/一居室出租）、公共区域运营（健身房/书吧/洗衣房）、社群活动、企业宿舍定制、品牌授权/运营托管；不做：分散式房源收房、房产买卖、短租/民宿 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 24小时管家+安保+门禁；合同到期15-30个工作日退还押金（无违约情形）；提前退租扣1个月租金作违约金（具体看合同）；投诉渠道：APP投诉、区域经理、12315 |
| 用户投诉集中点 | 服务费性价比争议（"每月500元服务费，只见过保洁一次"）；隔音差/基础设施老化（地板空鼓/热水器频繁故障）；续约时租金涨10%高于市场价；合同陷阱（提前退租扣费条款严苛）；押金退还拖延；部分门店服务缩水（公共区域保洁频率低/维修响应慢） |
| 优势维度 | 集中式运营效率高（1管家管50-80间）；全国门店风格统一（跨城市无缝切换）；安保+社区氛围优于民宅散租；稳定的一线/强二线城市门店网络 |
| 弱势/争议点 | 租金溢价明显（比周边民宅贵20%-30%）；服务费性价比屡遭质疑；非核心城市门店管理粗放（加盟店品质不稳定）；与保租房（政策型低价公寓）竞争中租金优势不足 |

|------|------|

| 押金退还规则 | 合同到期无违约15-30个工作日退还；提前退租一般扣1个月租金作违约金；退租需提前申请+清空物品+管家验房 |
