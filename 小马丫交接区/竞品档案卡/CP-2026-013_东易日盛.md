## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 基础施工利润（管理费占合同额8%-12%）+ 设计费（80-1500元/㎡按设计师等级）+ 供应链差价（主材集采/自有品牌产品）+ 定制家具+ 家电代销 |
| 佣金/收费结构 | 非平台模式 — 直营家装企业，按项目收费：设计费（80-1500元/㎡）+ 基础施工费 + 主材代购费 + 管理费（8%-12%）；套餐线速美超级家按面积打包（X99元/㎡）；远程施工费另计 |
| 数据透明度 | 中 — 合同附详细施工项目清单、设计师等级+收费公开；但不公布各城市分公司施工合格率/投诉率，部分加盟网点执行标准不统一 |
| 服务边界 | 做：中高端家装设计+施工（普通住宅/别墅/商业空间）、速美超级家整装套餐、全屋定制、主材代购；不做：平台撮合第三方装修公司、低端简装 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 官方承诺"恶意增项双倍赔付"；合同约定增项不超过5%；自有工人+标准化工艺体系；分四阶段验收（隐蔽/泥木/油漆/竣工）；投诉渠道：400客服、12315、黑猫投诉 |
| 用户投诉集中点 | 增项纠纷：签约承诺"无增项"/"0增项"，施工中增项远超5%（漏报拆旧/水电改造/墙面处理等）；工期延误无赔偿；施工质量：墙面开裂/漏水/瓷砖空鼓，售后维修拖延；退款难（终止合同后扣高额违约金）；虚假宣传（环保材料/设计师资质与实际不符） |
| 优势维度 | A股上市品牌信用（"跑路"风险低）；设计能力强（分层设计师体系）；自有工人+德系工艺体系（标准高于行业平均）；环保材料标签（专利工艺） |
| 弱势/争议点 | 收费显著高于中小装修公司；黑猫投诉超1000条，回复率60%/完成率40%偏低；2021-2023连续三年亏损（地产下行+加盟管理不善+数字化投入回报不及预期）；加盟网点施工质量与管理标准脱节 |

## 赛道扩展字段（家装）

| 字段 | 内容 |
|------|------|
| 增项率 | 官方承诺"增项≤合同额5%""恶意增项双倍赔付"；用户实际反馈增项常超5%，集中在拆旧漏报、水电改造超点位、墙面特殊处理、主材升级四类；"故意漏项"是投诉核心 |
| 合同透明度 | 合同附详细施工清单（项目/工艺/辅材），管理费8%-12%明示；但增项纠纷根因常在于前期报价阶段口头承诺未写入合同 |
| 材料环保等级公示 | 宣传强调"环保家装"标签，使用专利环保工艺；主材品牌/型号需用户主动确认，环保等级（E0/E1）依赖所选品牌公开信息 |
