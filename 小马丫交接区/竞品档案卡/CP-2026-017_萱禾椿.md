## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | B端佣金（养老院/护理院/适老化改造公司获客佣金）+ C端咨询费（规划服务费¥300-800/小时或¥5000-20000/家庭打包）+ 增值服务（家政/陪护/医疗资源对接分成）+ 会员年费 |
| 佣金/收费结构 | 免费模式：顾问免费带看养老院，成交后B端机构支付佣金（首月月费或年费比例）；咨询收费模式：按小时/项目收取规划费（¥300-800/时或¥5000-20000/家庭）；会员制年费（含全年法律咨询/陪诊/优先锁定床位） |
| 数据透明度 | 低 — 养老顾问行业通病：佣金比例不公开、机构推荐排序标准不透明、C端付费与B端佣金之间的利益冲突披露不足；中立性依赖品牌自觉 |
| 服务边界 | 做：老人身体能力评估（ADL/认知症筛查）、养老机构筛选与导览/代谈判价格、居家适老化改造方案设计、医疗资源对接（挂号陪诊/绿色通道）、法律与财务规划（意定监护/遗嘱/理财防骗）；不做：直接提供护理服务、自营养老机构 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 前期评估（ADL/认知症筛查/家庭财务状况分析）降低错配风险；顾问陪同实地考察养老机构/护理院；入住后跟踪+纠纷调解+方案调整；投诉渠道：品牌客服、12315 |
| 用户投诉集中点 | 中立性存疑（担忧顾问与养老院利益绑定、推荐偏向高佣金机构）；咨询费价值认知分歧（"直接找养老院销售不也一样""规划做得好后续跟不上"）；后续服务跟进不到位（签约后跟进减少、"管杀不管埋"）；行业无统一资质标准（养老顾问准入门槛低） |
| 优势维度 | 解决信息不对称核心痛点（子女没时间/老人不懂行）；C端付费+全周期陪伴模式区别于传统"一锤子"中介；覆盖"医养护财"全链条（远超传统中介仅做床位引导）；一人一方案个性化 |
| 弱势/争议点 | 养老顾问行业整体处于早期（无统一资质标准/监管缺位/用户认知度低）；中立性在B端佣金模式下天然脆弱；获客成本高（低频高客单，用户LTV有限）；与保险/保健品行业界限模糊易被误解 |

## 赛道扩展字段（养老）

| 字段 | 内容 |
|------|------|
| 服务深度 | 全周期：前期评估（ADL/认知症/财务）→ 机构匹配与代谈判 → 居家改造 → 医疗对接 → 法律财务 → 入住后跟踪调整 |
| 与传统中介差异 | 立场：C端买方顾问 vs 传统中介偏向B端；服务深度：长期陪伴 vs 一次性介绍入住即结束；专业度：涉及医疗护理/心理/法律 vs 纯销售导向仅介绍硬件价格；盈利：顾问费+佣金双重收入 vs 纯佣金 |
| 用户认知度 | 低 — 国内"养老顾问"品类仍处市场教育阶段，"花钱请人选养老院"的消费习惯未成熟 |
