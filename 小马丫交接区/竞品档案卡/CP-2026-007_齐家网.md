## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 商家入驻费/年费 + 线索费（按条）+ 交易佣金（合同金额3%-12%）+ 供应链差价（建材集采）+ "齐家保"监理/托管服务费（合同额2%-5%）+ 装修贷款导流佣金 + 增值服务（流量曝光/排名推广） |
| 佣金/收费结构 | 交易佣金：合同金额3%-12%（头部商家低、新入驻/促销订单高）；"齐家保"托管服务费：合同额2%-5%（用户端）；线索费：按条收费，转化率存争议；半包订单佣金通常低于全包 |
| 数据透明度 | 低 — 不公开各商家佣金比例、不公布监理验收通过/整改率、不公布商家筛选淘汰机制；半包/全包佣金差异非公开 |
| 服务边界 | 做：装修需求匹配、第三方节点验收（水电/泥木/油漆/竣工）、资金托管（"齐家保"）、建材集采、装修贷导流、线下体验店；不做：自营装修施工 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | "齐家保"资金托管（按节点验收后分批放款）+ 第三方监理验收 + 商家保证金制度；增项纠纷向平台申请介入，恶意的扣保证金/清退；投诉渠道：APP客服、12315、黑猫投诉 |
| 用户投诉集中点 | 平台推荐装修公司资质不全/低开高走/偷工减料→平台以"独立经营"推责；恶意增项比例偏高（增项比例约束5%-8%形同虚设）；资金托管形同虚设（施工不达标仍放款）；监理走过场；平台推送线索转化率低但照收线索费→商家成本转嫁用户；售后互相推诿 |
| 优势维度 | 品牌认知度较高（老牌互联网家装平台）；"齐家保"资金托管机制；线下体验店+线上撮合双渠道；建材集采压低部分成本 |
| 弱势/争议点 | 黑猫投诉累计超1.2万条，回复率/解决率偏低；平台对商家实质约束力弱（商家保证金远低于增项收益）；与土巴兔同质化竞争严重，差异化不足；用户口碑持续恶化→流量获取成本上升 |

## 赛道扩展字段（家装）

| 字段 | 内容 |
|------|------|
| 增项率 | 平台要求增项不超过合同额5%-8%，但实际执行中约束力弱；部分商家"低开高走"后增项远超约定上限，平台介入调解效果有限 |
| 合同透明度 | 要求入驻商家提供详细报价清单、承诺"无隐形增项"；但合同标准化程度低于土巴兔，各地执行标准不统一 |
| 材料环保等级公示 | 平台要求商家标注材料品牌型号，但环保等级（E0/E1等）依赖商家自觉公示，平台不强制审核环保检测报告 |
