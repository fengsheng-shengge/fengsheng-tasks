## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 二手房买卖居间佣金 + 新房分销佣金（开发商支付，成交价2%-5%）+ 租赁居间佣金 + 相寓长租公寓租金差+服务费 + 按揭/过户代办费（¥1000-3000/单） |
| 佣金/收费结构 | 二手房买卖：多数城市2%-3%，部分城市买卖双方合计可达4%（实际协商下浮，常见2%-2.5%）；租赁：1个月租金（租客付或双方各半）；相寓：1个月租金服务费；新房：开发商支付2%-5% |
| 数据透明度 | 中 — 门店公示收费标准+合同明示，APP标注"核验通过""真实委托"标签；但经纪人私下引流挂低价假房源仍存在 |
| 服务边界 | 做：二手房买卖/租赁居间、新房分销、相寓长租公寓运营、按揭贷款代办/过户代办/评估、商业地产运营；不做：平台化开放第三方经纪品牌（非贝壳式ACN平台） |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 房源真实性：门店"假一赔百"承诺（虚假房源核实后赔付）+ APP标注"核验通过"；交易安全：资金存管；投诉渠道：400客服、住建部门、12315、黑猫投诉 |
| 用户投诉集中点 | 佣金：未提前告知/捆绑收费/交易失败后拖延退佣；房源：虚假房源引流、隐瞒抵押/查封；相寓：押金克扣、随意涨租、维修拖延、"租金贷"诱导；经纪人：服务态度差、交易流程拖延、承诺不兑现 |
| 优势维度 | 线下门店密度高（全国覆盖广）、相寓依托中介网络获客成本低于纯线上长租品牌、二手房+新房+租赁+资管多元收入抗周期、A股上市品牌信用 |
| 弱势/争议点 | 佣金偏高（部分城市高于链家）；经纪人专业度参差不齐；相寓长租投诉高发（押金/涨租/维修）；品牌满意度弱于链家/贝壳；连续亏损压力 |
