## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 普通租赁：中介费（1个月租金，租客/房东协商承担）+ 省心租：月服务费（租金8%-15%）+ 增值服务（维修/保洁/换租协助） |
| 佣金/收费结构 | 普通租赁：一次性中介费1个月租金（贝壳不持房，ACN经纪人网络撮合）；省心租：月服务费8%-15%（贝壳托管房源，端到端包租务）；无额外服务费/卫生费 |
| 数据透明度 | 高 — 贝壳ACN约束房源真实性（假房源率低）；租金/押金默认走央行监管账户，资金流向可查；平台不直接定价（普通租赁房东定价、省心租贝壳根据房源成本+周边行情定价） |
| 服务边界 | 做：多主体房源聚合（普通民宅+托管省心租）、带看撮合、资金监管、省心租租务管理（维修/保洁/换租）；不做：自营集中式公寓（非自如寓/魔方模式）、自持房源资产 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 普通租赁：ACN经纪人真房源纪律（假房源扣分下架）+ 资金监管账户（租客付款先冻结、确认交房后打款）；省心租：托管合同直接与贝壳签+售后有平台追责路径；投诉：APP客服中心24小时响应/官方热线10106188/住建委/12315 |
| 用户投诉集中点 | 普通租赁：经纪人服务水平参差不齐（隐瞒房源缺点/噪音/瑕疵）；省心租：维修响应慢（部分城市服务人员不足/推诿处理问题）；普通租赁租后无后续服务（需自行对接房东）；贝壳平台对第三方经纪人约束力有限 |
| 优势维度 | 房源真实性行业领先（贝壳ACN体系）；普通租赁无后续服务费、成本低于自如；资金监管安全（杜绝中介卷款跑路）；房源类型多元（普通民宅+托管+公寓）选择面广；普通租赁可协商个性化需求（短租/养宠/租金支付方式） |
| 弱势/争议点 | 普通租赁租后服务为零（全靠房东）；省心租服务深度不及自如（管家体系/维修效率/保洁标准化）；省心租溢价与自如接近（比普通民宅贵10%-20%）；经纪人服务质量方差大 |

## 赛道扩展字段（租赁）

| 字段 | 内容 |
|------|------|
| 房源模式 | 双轨：①聚合模式 — 链家/德佑等ACN经纪人带看普通二手房/租赁房源（贝壳不持房）；②托管模式 — 省心租，房东委托→贝壳装修配置→出租+租务管理（分散式长租） |
