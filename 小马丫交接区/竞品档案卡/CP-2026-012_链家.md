## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 二手房买卖佣金 + 新房渠道佣金（开发商支付）+ 租房佣金 + 金融服务费（按揭/过户代办）+ 贝壳平台体系内的品牌分成 |
| 佣金/收费结构 | 二手房：多数城市2%-3%（北京/上海约2.7%）；新房：开发商支付成交额1%-5%；租房：1个月租金（租客付）；贝壳平台服务费：链家作为直营品牌向贝壳平台缴纳一定比例平台费，从总佣金中拆分 |
| 数据透明度 | 高 — 全国统一明码标价、交易前明确佣金比例及包含服务、禁止隐性收费；贝壳分评价体系公开；真房源标准清晰 |
| 服务边界 | 做：二手房/新房/租房居间交易、权证办理、按揭代办、资金存管、社区便民服务；不做：自营长租公寓（区别于自如）、平台化第三方品牌管理（由贝壳层面负责） |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 真房源承诺"假一赔百"；资金存管（定金/首付银行监管）；过户失败退佣金；物业欠费垫付；限时卖出（约定时间未卖出赔付）；多渠道投诉（APP/400/门店/公众号）+ 1工作日响应 |
| 用户投诉集中点 | 佣金费率偏高（部分城市实际收费向2.7%上靠）；经纪人隐瞒房屋缺陷；ACN内部协作纠纷（抢单/藏房源）；部分城市加盟店服务品质下滑；二手房交易周期偏长 |
| 优势维度 | 真房源体系行业标杆（楼盘字典+验真）；安心服务承诺覆盖面最广（9大承诺）；经纪人培训体系完善（持证上岗+贝壳分评价）；线下门店覆盖全国30+城市8000家直营；社区信任度高 |
| 弱势/争议点 | 佣金费率高于中小中介（2%-3% vs 1%-2%）；贝壳体系内链家与加盟品牌（德佑等）服务落差；部分城市市占率过高引发市场垄断质疑；双边代理模式内生利益冲突 |
