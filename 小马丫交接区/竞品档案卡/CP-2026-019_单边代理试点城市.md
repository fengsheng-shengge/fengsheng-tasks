## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 各付各佣：卖方支付卖方经纪人佣金 + 买方支付买方经纪人佣金（传统模式下佣金通常由买方单方承担或协商分摊）；各付各佣尚在培育中 |
| 佣金/收费结构 | 深圳传统模式：成交价1%-3%（买方或协商承担）；单边代理推进后：买卖双方各付各自经纪人佣金（金额透明化）；杭州仍以传统模式为主，渐进调整 |
| 数据透明度 | 高（改革方向）— 深圳房源编码制度（唯一官方编码可查权属/抵押/查封/有效期）；杭州城市大脑+交易监管平台；买家可官方渠道实时验证房源真实状态 |
| 服务边界 | 做：买方经纪人仅代表买方（谈判压价/尽职调查/法务支持）、卖方经纪人仅代表卖方（定价建议/营销推广/谈判）；不做：一中介同时代理双方（这正是要打破的传统模式） |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 深圳：房源编码强制核验（杜绝虚假房源/重复挂牌/信息不对称）+ 买方经纪人fiduciary duty（将同信任责任）法律强化；杭州：二手房交易监管服务平台+挂牌房源统一核验；投诉渠道：住建部门、12315 |
| 用户投诉集中点 | 传统双边代理的核心投诉（正是单边代理试图解决的）：中介两头吃（压低卖价+推高买价赚差价）、选择性披露信息、虚假房源钓鱼、佣金不透明；单边代理试点后：部分买方不愿额外支付买方经纪佣金（"以前都买房方免费"认知惯性） |
| 优势维度 | 根除利益冲突（经纪人仅忠于委托一方）；房源真实性系统保障（编码制度）；信息透明化（独立经纪人分别提供尽调/评估）；佣金支付关系清晰；推动经纪人专业化转型（从"撮合员"升级为"专业顾问"） |
| 弱势/争议点 | 市场接受度仍需培育（改变20年+消费习惯）；买方支付买方经纪人佣金的意愿是最大阻力；中小中介生存困难（专业分工要求高+资源不足）；法律配套滞后（《房地产经纪管理办法》仍以双边代理为默认框架）；跨中介协作规则未统一（不同机构经纪人如何协作+佣金结算无标准） |

## 赛道扩展字段（房产）

| 字段 | 内容 |
|------|------|
| 佣金结构 | 各付各佣（改革方向，买方/卖方各承担）；深圳已开始尝试，杭州仍以传统为主 |
| 房源真实性机制 | 深圳：唯一房源编码 + 住建局官网可查权属/抵押/查封/有效期 + 头部中介ACN系统配合；杭州：挂牌房源统一核验 + 城市大脑监管平台 |
| 双边/单边代理模式 | 单边代理：卖方和买方各自独立委托不同经纪人（试点阶段，尚未全面推广；2021-2024年深圳/杭州先行） |
