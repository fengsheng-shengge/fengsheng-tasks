## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 租金收入（核心）+ 配套商业运营（底商/社区服务）+ 增值服务（家政/社群活动/租房分期）+ REITs/资产证券化退出（如上海城投宽庭保租房REITs 2024年1月上市） |
| 佣金/收费结构 | 非佣金模式 — 机构房东直租：北京保租房租金¥60-120/㎡/月、深圳人才住房¥30-80/㎡月、保租房¥40-100/㎡/月、上海保租房¥80-150/㎡/月；租金为市场价60%-90%；无中介费；押金通常1个月租金 |
| 数据透明度 | 高 — 租金分档明确（政府指导价或市场价折扣公示）；房源申请条件/流程公开（各地住建部门官网+国企平台App）；配租结果公示 |
| 服务边界 | 做：保障性租赁住房供给+人才住房+保租房运营（在线选房/签约/缴费/报修）；不做：二手房买卖居间、商业化房产中介、利润最大化导向的纯市场化租赁 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 国企信用（"跑路"风险接近零）；租金受政府指导（不随意涨租）；配租结果接受社会监督；投诉渠道：平台客服、12345市民热线、住建部门 |
| 用户投诉集中点 | 申请门槛高（户籍/社保/学历等限制，深圳需全日制本科以上优先、北京需户籍或工作居住证+收入限制）；房源总量不足、轮候时间长；部分项目地理位置偏远/配套不足；退租流程繁琐；装修标准参差不齐 |
| 优势维度 | 租金显著低于市场价（10%-30%折扣）；稳定性极高（国企运营+政府指导租金，不随意涨租/驱赶）；无中介费/服务费/隐形收费；全流程线上化（App选房→签约→缴费→报修）；REITs退出机制为长期运营提供资本循环 |
| 弱势/争议点 | 覆盖人群有限（非普惠，有准入门槛）；市场化程度低（盈利周期长达10-15年）；新项目多位于城市外围产业园区（通勤便利性不足）；存量改造成本高、供需区域不匹配；服务品质不及自如/贝壳（数字化运营和管家服务标准化较弱） |

## 赛道扩展字段（租赁）

| 字段 | 内容 |
|------|------|
| 房源模式 | 重资产：国企自持新建/存量改造物业；轻资产：与村集体/企业合作改造存量房源收取管理费；政企合作：定向配租园区企业/单位获取稳定客源 |
| 租金水平 | 保租房：市场价60%-90%，各城市差异大（北京¥60-120/㎡/月、上海¥80-150/㎡/月、深圳¥30-80/㎡/月）；人才住房最低可达市场价50% |
| 押金与退租 | 押金1个月；退租按各地保租房管理办法执行（通常提前1个月申请）；无中介费/服务费 |
