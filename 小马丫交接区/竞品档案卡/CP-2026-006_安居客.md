## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 端口费（经纪人/中介购买发布权限，占收入大头）+ 广告/营销服务 + 排名推广/增值服务 + 新房楼盘合作 + 线索费（部分城市按电话/咨询收费） |
| 佣金/收费结构 | 不向购房者/房东收佣金；B端按城市等级收端口订阅费（月度/季度/年度）+ 房源置顶/排名推广费 + 新房按项目合作收费；无统一成交抽佣比率 |
| 数据透明度 | 低 — 端口费价格不公开、推荐算法排序规则不透明、房源真实性依赖中介自觉，平台不对房源内容做实质审核 |
| 服务边界 | 做：房源信息展示（二手房/新房/租房）、流量分发、经纪人获客、楼盘广告、数据服务（区域市场分析）；不做：房产交易撮合、资金托管、合同签署 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 平台内投诉+举报机制（虚假房源可举报下架）；无交易资金托管、无成交兜底赔付；投诉渠道：APP客服、12315、黑猫投诉 |
| 用户投诉集中点 | 虚假房源（低价引流/已售未下架）；同一房源多账号重复发布；经纪人电话骚扰（提交需求后多家中介轮流拨打）；端口费逐年上涨→中小中介获客成本高→转嫁用户；大中介获算法流量倾斜 |
| 优势维度 | 流量大（58同城生态加持）、覆盖城市广（全国数百城）、使用门槛低、信息更新快、对新房开发商有较强营销价值 |
| 弱势/争议点 | 房源真实性管控弱（不参与交易→不验证产权），"虚假房源"标签难以摘除；平台对经纪人约束力极弱（端口费模式下中介是客户而非被管控方）；"端口模式"天花板明显（流量红利见顶+竞品蚕食） |

## 赛道扩展字段（房产）

| 字段 | 内容 |
|------|------|
| 佣金结构 | 不收取交易佣金——安居客的核心收入是B端端口订阅费+广告推广费，非成交抽佣 |
| 房源真实性机制 | 依赖中介自觉+用户举报下架，无楼盘字典级验真体系；相比贝壳的"假一赔百+ACN扣分"，安居客的房源真实性保障力度明显较弱 |
| 双边/单边代理模式 | 不参与代理——安居客仅做信息分发，买卖双方直接对接发布房源的中介/经纪人，平台不介入委托关系 |
