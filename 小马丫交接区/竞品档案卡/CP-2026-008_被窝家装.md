## 商业模式

| 字段 | 内容 |
|------|------|
| 收入来源 | 套餐费（按建筑面积¥800-1500/㎡）+ 个性化增项费（主材升级/工艺升级/定制柜体）+ 管理费（合同额5%-10%，含设计监理售后）+ 供应链差价（主材/辅材集中采购） |
| 佣金/收费结构 | 非平台抽佣模式 — 被窝作为直营装修方，直接向业主收取套餐+增项费用；付款分阶段：签约30%→水电30%→泥木20%→竣工15%→质保金5% |
| 数据透明度 | 中 — 套餐价格公开、APP可查看施工进度+材料记录；但不公布真实增项平均比例、不公布各城市工长合格率/投诉率 |
| 服务边界 | 做：标准化整装（基础施工+主材+部分软装）、个性化定制升级、APP工地直播、贝壳统一售后；不做：纯设计服务、建材零售 |

## 服务质量

| 字段 | 内容 |
|------|------|
| 兜底机制 | 贝壳平台统一售后（APP客服/400热线）；部分城市采用"产业工人"模式（公司直管非外包）；施工验收标准（水电拍照存档/48小时闭水试验）；投诉渠道：APP客服、12315、黑猫投诉 |
| 用户投诉集中点 | 前期报价漏项→签约后增项（水电点位不足/老房铲墙皮/墙面挂网等，增项可达套餐费10%-30%甚至50%）；工期延误（合同3个月拖延1-2个月）；材料不符（同品牌低档次系列/色差）；工长/设计师/售后互相推诿 |
| 优势维度 | 贝壳品牌背书（比小公司"跑路"风险低）；APP进度追踪+材料记录；标准化套餐降低决策成本；部分城市"产业工人"模式提升施工规范性；统一售后体系 |
| 弱势/争议点 | 增项投诉高发（"零增项"承诺与执行脱节）；工长水平参差（部分城市仍用外包）；监理走过场（墙面平整度/瓷砖空鼓未检出）；黑猫投诉解决率不理想 |

## 赛道扩展字段（家装）

| 字段 | 内容 |
|------|------|
| 增项率 | 官方宣称"增项需提前告知并签字确认"；实际用户反馈增项可达套餐费10%-50%，主要集中在：水电点位增加、老房铲墙/找平、主材升级、墙面特殊处理（挂网等） |
| 合同透明度 | 标准化套餐合同（含基础施工+主材清单），但套餐细则（水电点位数量/主材可选范围）容易成为增项源头；承诺写入合同的比例偏低 |
| 材料环保等级公示 | 套餐内主材以"一线/二线品牌"名义标注，品牌具体型号及环保等级（E0/E1）需用户主动确认，非主动公示 |
