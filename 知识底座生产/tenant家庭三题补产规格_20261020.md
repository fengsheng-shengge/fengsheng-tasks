## 一、补产范围与目标量（小眼镜裁定：三组，每组 target 20-30 条）

### 组 1 · 子女就学（租客视角）｜target 20-30 条
**消费者原话样本**（cq 必须写成租客第一人称疑问句）：
- "我租的房子孩子能上对口学校吗？"
- "租房子的孩子上学要交什么材料？"
- "非京籍的孩子在租住房能入学吗？"
- "租售同权到底怎么落实？入学审核看什么？"

**必须覆盖**：
- 入学资格：租客子女随迁入学条件（居住证 + 社保/纳税/工作等材料，各城市口径不同须标城市）
- 就近入学：租住地址能否对应划片学校、学位是否被占用
- 学位占用：租赁备案与学位占用关系（呼应 P2-C1-015）
- 材料清单：居住证、租赁备案、社保缴纳记录、劳动合同等
- 政策变化：多校划片/六年一学位对租客的影响
- 时间节点：报名期、材料提交截止、入学资格审核公示
- 差异提示：租客入学 vs 购房入学 vs 集体户/单位户

**可参照改写的既有词条**（buyer 视角，改写成租客视角即可）：
`PRE-SCH-001` 学区划片规则 / `PRE-SCH-002` 六年一学位 / `PRE-SCH-003` 多校划片随机派位 / `PRE-SCH-005` 怎么查学区名额有没有被占用 / `PRE-SCH-007` 户口没迁过来孩子能上学吗 / `PRE-SCH-012` 中介承诺学区有法律效力吗 / `PRE-SCH-022` 学区划片调整有法律救济途径吗 / `PRE-SCH-032` 买学区房户口必须迁过来吗 / `PRE-NEED-120` 家里有小孩选房注意什么

### 组 2 · 租房家庭落户与学籍｜target 20-30 条
**消费者原话样本**：
- "租房能把户口迁过来吗？"
- "我在租的房子能办居住证吗？"
- "租房社保怎么缴？断缴影响孩子入学吗？"
- "退租之后户口要不要迁出？不迁有什么后果？"

**必须覆盖**：
- 居住证办理条件与流程（呼应 `RENT-086` 租房去办居住证需要什么）
- 租房落户政策（各地差异大，须标城市口径）
- 社保缴纳：公积金抵租（呼应 `RENT-025`）、本地社保缴纳（呼应 `RENT-085`）
- 学籍与户籍/居住证的关系
- 退租后户口迁出义务与违约（可参照 `EXT-TRM-008` 退租后户口要迁出吗）
- 居住证积分/入学资格关联

**可参照改写**：`RENT-025` 公积金抵租 / `RENT-085` 租房社保能不能在本地缴 / `RENT-086` 居住证 / `EXT-TRM-008` 退租后户口迁出 / `PRE-SCH-007` 户口没迁过来孩子能上学吗

### 组 3 · 租客通勤决策｜target 20-30 条
**消费者原话样本**：
- "为了便宜租到郊区，每天通勤两小时值不值？"
- "看房时怎么实测通勤时间？"
- "地铁口近的房子租金贵多少？"

**必须覆盖**：
- 通勤时间实测方法（可参照 `PRE-MATCH-076` 通勤到公司实际多久怎么测）
- 租金与通勤的性价比权衡（呼应 `RENT-172` 租房要不要为了便宜选很远的郊区）
- 地铁/公交沿线租房溢价
- 换乘次数、步行接驳距离
- 早高峰实际耗时 vs 地图估算

**可参照改写**：`PRE-MATCH-076` 通勤实测 / `PRE-MATCH-099` 同价位不同区域怎么选 / `RENT-017` 租房是选离公司近还是便宜点的 / `RENT-172` 郊区 vs 便宜

## 二、字段与质检口径（沿用知识库铁律，不放宽）

沿用 24 字段契约，**字段名与权威库一致**（`detail`/`ola`/`cp`，不是 `def`/`oneLineAnswer`/`corePoint`）：

| 字段 | 要求 |
|---|---|
| `id` | 建议 `RENT-TEN-0xx` 续号（现有 001/002/003），或沿用被改标条目的原 id |
| `name` | 租客口吻疑问句或短标题 |
| `alias` | **数组**，≥5 个真实口语搜法 |
| `cq` / `consumerQ` | 消费者第一人称原话（疑问句） |
| `ola` | ≥21 字，一句话答案 |
| `cp` | **数组**，≥3 条要点（本库实际水位 3-5，**不要硬凑 8**） |
| `detail` | ≥130 字，含政策口径 + 实操指引 + 风险提示 |
| `legalRef` | **必须真实可溯**（义务教育法、居住证暂行条例、各市入学政策文件等）；无直接法源标「待补充」，**严禁编造** |
| `ownerBenefit` | 从**房东/二房东视角**写价值（与 RENT-TEN 体例一致） |
| `tags.clientType` | **必须含 `tenant`**（否则策展轴加权不命中，条目会沉默） |
| `sceneDomain` | 建议 `租住`；就学类可用 `学区教育` |
| `subScene` | 就学 → `租住·政策福利` 或新增 `租住·子女就学`；落户 → `租住·政策福利`；通勤 → `租住·地段选择` |
| `severity` | 就学/落户 = `hard`；通勤 = `medium` |
| `caseRef` | 有案例填 id，无则「待补充」（小眼镜 14:31 已交付映射清单，落库后统一回填） |

**视角铁律**：租客**第一/第二人称**，不照抄业主措辞。业主侧体例只作结构参考。
