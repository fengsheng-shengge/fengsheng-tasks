```
│   └── CHANGELOG.md       # 动态更新日志（批次/变更/拍板链）
└── scripts/               # 守门工具（D1 字段体检/D2 dry-run/五关检测）
```

## 二、调取协议（产品侧必读）

1. **调取**：读本仓库固定路径文件（GitHub raw），消费时锁定文件 md5/版本号，不硬编码中间值
2. **口径**：一切字段语义/枚举/规则以 `DICTIONARY.md` 为准（当前 v1.3）；数据文件与字典冲突时以字典为准并报内容线修正
3. **变更感知**：内容侧每次更新在 `updates/CHANGELOG.md` 记录（改什么/md5/拍板人），同步群通知；消费方按自身节奏升级版本
4. **需求回流**：产品侧需要新字段/新数据 → 群内提出 → 内容线登记字典 GAP → 排期采集 → 审核入库 → CHANGELOG 通知。产品侧不直接改数据文件
5. **守门**：数据文件入库前必经 D1 字段体检 + D2 dry-run preview + 小酒窝儿审核；未经审核的文件不进 data/
