# 风声 运营冷启动工具包（经纪人版 · 2026-08-05）

> 适用：审核通过后内测经纪人。目标：用风声把"一个客户"服务明白，拿到真实好评，启动口碑飞轮。
> 配套规划：风声_V3.1_运营与迭代规划_20260805.md

## 1. 风声是什么（一句话给经纪人）
风声是你每次见客户（尤其线下见面）的「见面策展工具」：见面前列好要"说 / 带 / 问"的几件事，见面后埋好"持续关怀"的引子。帮你用独立价值获得客户尊重。

## 2. 第一次用：服务好"第一个客户"
1. 打开风声 → 客户档案 → 新建客户（选类型：租客 / 买房 / 业主 / 房东）。
2. 点「生成策展包」→ 选客户当前人生节点（如 买房-首套、租住-起步）。
3. 拿到策展包：**说 X 句 / 带 X 样 / 问 X 个问题** → 见面照着做。
4. 见面后点「见后跟进」→ 埋下持续关怀引子（部分功能后续版本开放，先留白）。
5. 客户满意 → 信任积分 +1（真实动作获得，不可购买）。

## 3. 信任积分（真实动作激励，非货币）
- **怎么得**：完成一次策展 / 存档一个客户 / 做一次见后跟进。
- **有什么用**：见证你"服务了多少客户、哪些节点最有用"，是独立价值的标尺，不是能买会员/权益的币。
- **铁律**：初始 0，靠真实动作涨；风声不卖任何虚拟权益（无会员/VIP/充值/订阅）。

## 4. 标杆策展包（抄作业模板，4 类各一）
- **买房-首套**：说「首付与月供测算口径」/ 带「同小区成交类比」/ 问「通勤与学区权重」。
- **租住-起步**：说「押一付一与合同要点」/ 带「周边配套清单」/ 问「租期与宠物」。
- **业主出售**：说「定价与带看节奏」/ 带「同户型近期成交」/ 问「售房真实动机」。
- **房东出租**：说「租金回报与空置风险」/ 带「租赁条例要点」/ 问「出租偏好」。

> 注：业主出售 / 房东出租 两类标杆模板当前为"结构示意"，待 V3.1 引擎接入真实数据后补全法源与案例。

## 5. 飞书群「今日策展」打卡
每天发一条：今天为哪个客户做了策展包 + 客户一句反馈。沉淀复利，互相抄作业。

## 6. 常见问答
- **Q：客户能看到我的策展包吗？** A：可生成「客户可见页」转发/打印，隐藏内部清单与探测问，只露有形价值。
- **Q：数据真实吗？** A：依据映射真实词典，绝不编；暂无真实数据的区块会隐藏而非编造。
- **Q：会不会泄露我的客户？** A：客户档案本地存储，风声不收经纪人数据（"站经纪人给尊严不收数据"）。
