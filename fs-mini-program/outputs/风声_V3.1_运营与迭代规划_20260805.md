# 风声 V3.1 运营与迭代规划（2026-08-05 · 小豆子）

> 背景：V3.0.13.1 已提交微信审核（用户 8.5 14:20 提交，审核中）。审核期代码冻结（已提交包不可改），迭代在特性分支另起 V3.1。本文规划「运营冷启动」与「V3.1 迭代」两条线，确保审核期间不空转、过审即放量。

## 一、产品北极星与飞轮（运营一切动作的锚）
- 北极星（客户行为）：①留好印象 ②持续选他 ③最终成交。
- 发心：帮经纪人把一个客户服务明白 → 真实口碑正反馈 → 持续选他。
- 飞轮：用风声策展 → 客户留好印象 → 转介绍 → 信任积分涨 → 更愿用 → 服务更多客户。
- 铁律：用户=经纪人；客户是经纪人的客户。凡功能用「有用吗？好用吗？会持续用吗？」裁决。信任积分仅真实动作获得、不可购买。

## 二、运营（冷启动 + 口碑飞轮）— 审核期即可全面推进
### 阶段 0：内测冷启动（审核通过后 2 周内）
1. **内测名单**：飞书群内经纪人（生哥团队 + 受邀同行），1v1 教会用「第一个客户」。
2. **标杆策展包样例**：购房首套 / 租住起步 / 业主出售 / 房东出租 各 1 份（"抄作业"模板，见《运营冷启动工具包》）。
3. **经纪人使用指南（图文）**：见面前怎么策展、见面后怎么跟进、信任积分怎么涨。
4. **信任积分机制说明**：仅真实动作获得（完成策展 / 客户存档 / 见后跟进），对应"独立价值获得尊重"，非币非可购。

### 阶段 1：口碑飞轮（持续）
- 飞书群「今日策展」每日打卡，沉淀复利（一次委托终生服务）。
- 标杆经纪人案例群内分享 → 邀请同行 → 增长。
- 收集"客户原话好评"反哺使用指南与标杆模板。

### 阶段 2：增长（审核通过后放量）
- 按 4 客户类型（租客/买房/业主/房东）分场景运营内容。
- 策展包模板库上线后，经纪人互享模板，降低使用门槛。
- 真实口碑素材（客户好评截图/转介绍故事）做对外内容。
