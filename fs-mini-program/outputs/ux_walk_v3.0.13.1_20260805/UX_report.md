## 二、核心结论

- **有用性 ✅**：策展包"说→带→问+见后跟进"可执行；购房/租住/出售线法源扎实（R1 34/40、R3 35/40 真实法源）；导出工具闭环（客户页/HTML/豆包/摘要/认知卡）全通。
- **好用性 ⚠️**：流程顺滑；主要 friction 为 房东出租线空包（R4 0 命中，已诚实提示）与 dataRef/caseRef "待补充" 高频出现。
- **会持续用吗 ⚠️**：取决于 dataRef/caseRef 补全速度与房东出租线修复。

## 三、关键发现

1. **房东出租线（R4）完全空包**：say/bring/ask 全 0，根因特性分支 slim landlord 数据 0；页面诚实提示"该场景下暂无匹配词条"，不崩溃。→ P0 待 slim union 768 修复。
2. **CORS 埋点噪音（已修）**：原 `tracker.js` 直连 fengsheng.tech 在 H5 本地刷 CORS 报错；已加本地跳过，重跑 0 报错。
3. **客户可见页诚实降级**：dataRef/caseRef 0% 时显示版式示意并提示"真实数据补入字典后自动替换"，无假数据。
4. **无客户存档分支**：点"存入客户认知卡"出现"未关联客户"诚实 toast，不假存。
